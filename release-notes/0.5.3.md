- **低功耗**：默认用普通模式，以前选过低功耗的电脑升级后也从普通模式开始。低功耗下灯光工作台的时间线不再消失。
- **开播检查**：同一首歌的同一类问题，选过一次「无灯光播放」后不再重复弹窗，屏幕上照常提示本首无灯光，日志也会记下。这首歌检查通过后又出问题、问题换了一类，或者重开软件，会再问一次。
- **侧栏任务**：侧栏只显示正在进行的任务。素材读取、属性读取和音乐分析结束后弹出一次结果，成功的自动关闭，失败的留到手动关闭。侧栏去掉了「检查空 Cue」按钮。
- **更新日志**：「设置 › 外观与更新 › 软件更新」里可以查看各版本的更新内容；发现新版本时，可以打开官网下载页查看新版本改了什么。
