    授权、设备与联网

    一份激活码绑定一台电脑，无免费版或试用。每次启动需要联网验证；验证失败不能进入工作区。换机请联系支持，不能直接在另一台电脑重复激活。

    期限从什么时候开始？

    月付按 30 天、年付按 365 天计算，包含对应期限的使用与更新权益。首次付款经服务端核实并发码时起算，不从首次安装起算。续费在已激活电脑的软件内办理。

    交付、退款与发票

    支付成功以服务端确认结果为准。未收到激活码、需要退款或开票时，请提供订单号联系 info@jinhefilm.com。不要发送订单凭据或完整激活码。自动开票尚未开放。

    下载与现场使用

    适用于 Windows x64。当前安装包未做代码签名，Windows 可能提示未知发布者。OBS 负责正式画面与输出，联动台不控制开播、关播及录像。现场设备适配需按你的实际环境验证。

    订单数据与隐私

    下单记录购买人或公司名称、套餐、金额和状态。浏览器在当前标签会话内保存订单领取凭据，导出的凭据由你保管。软件激活时提交机器标识，用于授权绑定。
