# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
团播工作室、现场操作人员，以及采购 Windows 节目编排工具的个人与公司。

## Product Purpose
团播联动台连接节目单、时间线、Cue、OBS、MIDI 和 MTC。官网帮助用户了解实际工作流、下载 Windows 软件、选择授权并取得激活码。

## Capabilities and Constraints
- 月付 800 元 / 30 天 / 台；年付 8,000 元 / 365 天 / 台。服务端目录为定价依据。
- 无免费版和试用，无客户注册账户。激活码绑定电脑，每次启动联网验证。
- 主动续费，不自动扣款。OBS 负责输出，不控制推流或录像。
- 保留订单凭据导出、恢复、核款和交付流程。正式付款不能由模拟记录替代。
- 自动开票尚未接入。Windows 安装包尚无 Authenticode 签名。

## Brand Commitments
使用「团播联动台」产品名。用户要求官网不展示公司全称，月付和年付套餐在同一页面直接展示。联系邮箱 info@jinhefilm.com。

## Evidence on Hand
软件源码、正式 Windows 安装包、授权与更新验收记录。没有用户提供的演示视频、客户案例或业务效果数据，不虚构。

## Product Principles
- 先让用户看懂用途，再选择明确价格和期限的授权。
- 所有套餐放在同一页，服务失败时明确提示，不冒充可售。
- 无凭证不进入工作区，保留付费订单恢复能力。
