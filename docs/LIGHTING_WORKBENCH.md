# 灯光工作台

2026-09-15：用户要求新增独立灯光工作台，优先改善现有音频分段和波形编辑。

## 已实现

- 左侧独立「灯光工作台」入口，直接选择现有节目，复用工程、音频编辑、播放、灯光轨道及 MA2 工具。
- 工作台不展示 OBS 画布和视觉轨道；原编辑器保留。切回原编辑器可以继续编辑相同内容。
- 音轨默认高度 220px，可调至 140–360px；显示增益 0.25–4 倍，仅影响波形显示。
- 短节目按约 2ms 保存峰值，最低 4800、最高 500000 个峰值；旧精度缓存重新生成。仍为第一声道幅度包络，镜像显示不代表独立左右声道或有符号采样。
- 编灯段落复用 LightingDocument.markers 的区域：命名、输入起止时间、按播放头设置边界、定位、删除；可在原时间尺拖动边界、双击改名。
- 编灯段落保持音频连续。需要实际切片时使用「切开音频」，或在工作台时间线上直接按 S，无需选中音频。切分当前音轨上播放头所在的片段。
- 工程变更经过既有 LinkCommand/store，支持保存和撤销/重做；播放中禁止灯光修改。

## IBT 节拍检测替换（2026-09-15）

- 删除旧 TypeScript 节拍检测和追踪实现，使用从公开 Marsyas 源码编译的 Windows IBT。固定源码、构建方法和许可见 [tools/ibt/README.md](../tools/ibt/README.md)。未复制 BeatEdit 商业插件或其封装代码。
- FFmpeg 将工程当前参考音频解码为单声道 44.1kHz PCM；IBT 离线分析保留实际节拍时间，不将节拍强制铺成等距网格。静音输入直接返回空结果，避免 IBT 在静音上生成虚假节拍。
- 「检测节拍」获取结果；「稀疏/标准/密集」分别取每四拍、每两拍、每拍；「应用标记」保存标记供 Cue 吸附；「按节拍切分音频」实际切分当前音轨，支持撤销。第一检测点不保证是音乐重拍，节拍检测不等于主副歌/八拍段落识别。
- 独立临时目录和相对参数兼容中文路径；缺失引擎、解码或分析失败明确报错，无旧算法回退。旧工程标记仍可读取，用户重新检测并应用后更新。
- 开发、构建和测试自动准备 IBT；发行资源包含 exe、完整对应源码、GPL 许可及构建说明。新增主进程组件后需要完整重启桌面应用。
- 桌面 `387..MP4`（约 37.88 秒）原生分析得到 72 个节拍点；这是运行验证，未与 BeatEdit 同片输出或人工标注比较，不代表商业版本同等精度。
- 隔离 Electron 实例通过真实 IPC 分析上述文件，保存 72 个密集节拍；标准密度 36 个切点生成 37 个片段，撤销恢复一个片段，无页面错误。自动化灯光工作台用例同时覆盖检测、保存标记、批量切分和撤销。未修改用户原工程。

## WaveSurfer.js 接入（2026-09-15）

- 使用固定版本 7.12.12，替换音频片段的自绘 Canvas。许可声明随 Windows 应用资源分发。
- 灯光工作台解码真实声道数据，只将可视区对应的原始采样传给组件，按片段源偏移对齐；普通编辑器使用已有峰值缓存。
- 按用户反馈移除全曲概览。工作台默认 220px/s，直接查看数秒的局部细节；保留全部、缩放与滚动。
- 频谱使用官方 Spectrogram 插件，在 Worker 内计算当前可视区；发生错误明确展示，不静默退回主线程。
- WaveSurfer 不接入音频输出，不负责播放、工程修改或实际切片。沿用既有时间源、LinkCommand、撤销与 S 切分。
- 桌面 387..MP4 在隔离 Electron 实例中验证波形与频谱，无页面错误；截图位于 output/waveform-review。
- 用户报告的正式播放准备失败单独排查：日志随后显示工程、集成档案、音频、波形缓存及 OBS 通过预检；用户随后确认界面已恢复，可以继续。初始化失败现在记录日志并保存错误，预检分别提示未加载工程、未保存工程或未加载连接配置。

- 默认节奏波形使用 Web Audio 离线高通 45Hz、低通 180Hz 的显示参考，突出低频起落；不改变原始媒体或正式音频。可切回原始波形和频谱。双声道使用单条合并波形，避免重复占据轨道高度。频率滤波可能带来微小相位偏移，精确切点仍需原始波形与试听确认；不把它当成自动鼓点识别。

- 修复点击波形轻微拖动造成起点偏移：波形主体只定位，标题用于移动片段，两端用于裁剪。当前音轨只有一个片段且起点大于零时，显示「音频贴齐开头」，通过既有编辑命令消除前置空隙，可撤销。Electron 用例覆盖 63ms 空隙恢复及主体误拖保护。
