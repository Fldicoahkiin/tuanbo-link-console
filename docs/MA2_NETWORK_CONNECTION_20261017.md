# MA2 电脑 IP 与一键连接修复（0.4.49）

## 已确认的软件问题

1. 顶部一键连接在有已保存控台时直接连接，绕过设置页的网卡准备；无已保存目标时也没有默认准备回调。
2. 设置页输入控台 IP 后将默认密码清空并标为未编辑；新目标没有安全存储密码时，实际提交空密码，导致正确 IP 仍不能登录。
3. 旧原生地址检查仅等待 5 秒，将 Windows DAD 检测超时、真实 Duplicate 和地址已存在混成同一条「地址冲突」提示。
4. 已存在地址没有持久保存网卡选择；未应用的网络方案却能影响连接源地址，失败方案可能留下不可用绑定。
5. 顶部连接错误地依赖本机 onPC 启动成功，阻断本来不需要本机 onPC 的实体控台。
6. 连接后缺少工程或节目 Cue 读取失败，会被界面混入「连接失败」语境。

## 当前交互

- 外部控台只需填控台屏幕上的 IP；电脑 IP 默认自动选择，手动指定单独开启。
- 控台 IP、电脑网卡及实际地址清单直接展示；「检查电脑与控台网络」仅生成方案，不修改网卡、不登录控台。方案在连接按钮上方显示网卡、地址和目标。
- 优先复用已有 Preferred 地址及真实掩码；没有同段地址时生成同段候选，连接动作才申请 Windows 管理员权限并添加临时地址。没有关闭 DAD，也没有将候选地址宣称为已经无冲突。
- 顶部和设置页共用准备流程。选择在应用成功后保存；重开软件仍使用该网卡，失效时明确报错。保留现有上网 IP、DHCP、网关、DNS。
- 新目标的 administrator 使用界面中的默认 admin；已有目标保留自己的安全存储凭证。改过密码时需填写实际密码，不自动尝试多组密码。
- Windows 地址已存在、DAD 确认冲突、15 秒检测超时、清理失败分别提示。只有 Preferred 才作为可用地址；失败撤回本次新地址，清理失败保留恢复入口。
- TCP 端口拒绝、不可达、端口已通但登录失败分别提示；后两阶段不会要求盲目更换电脑 IP。
- 本机程序失败不再阻断外部控台连接；本机连接仍在发送凭证前验证选定进程。
- 未打开工程时可以完成 MA2 登录；节目读取失败明确显示「网络已连接，Cue 载入未完成」。
