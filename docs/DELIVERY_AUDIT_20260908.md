## 使用边界

配套工程含原有的三个节目和对应素材，P1 文件已经指向交付目录内素材，不依赖 Downloads 原视频。此 `.hia` 的媒体路径针对本机交付位置，移动目录后需重新读取/生成映射。

P1 暂停与停止均停止输出 MTC，所以默认冻结画面，不能据此区分两种意图。联动台“停止联动”会清理画面并暂停监听；之后可恢复监听。未知区间、中途首次接入和异常跳变必须从头播放，不能假装自动同步成功。

素材不经软件有损转码，但原片的压缩/分辨率损失及直播平台再编码不可能由联动台消除。机位验收用现有显示器采集来源，实体摄像头和灯光控台未冒称已验收。当前账户安装验证不能替代干净 Windows 账户验收。
