# 0.4.57 MA2 同步与三层页面交付验收

日期：2026-10-21。范围为 Windows 本地软件、隔离 grandMA2 onPC 3.7.0.5 和完整免激活功能测试包。本轮按用户要求停止远程操作，没有访问用户现场控台；本记录不代替实体灯具终验。

## 最终行为

- 控台页面按 Button / Fader / Button 三层显示原格位。三层独立输入页码和翻页，中层为原生功能按键，没有竖推杆或额外登录。
- 上层 101–190、中层 1–15、下层 101–115；额外范围可切到中层 16–100、上层 191–240。名称不拼接序列编号，地址作为次要信息显示。
- 单击调用原生按键，Flash 等按住功能在松开、失焦、断线租约到期后释放。右键编辑、改名、移动、删除执行器分配；删除分配保留 Sequence 和 Cue。
- 默认时间线区域缩小；1180×780、1600×1000、1920×1080 三种窗口均能完整展示三层。保持用户手动调整的分区比例；核对界面不重复列出整曲删除卡片。
- 实时同步首次默认开启，主动暂停会保留。每首新歌默认创建于按钮 1000 页的可用空格，工程可设置其他默认页；已有绑定保持原位置。
- 本地编辑、保存、撤销与网络同步分开；意外断线后核对原序列并续传，不重放过期灯光按键。同字段两边修改需逐项核对，其他修改继续。
- 原生移动已成功但桥会话刷新时，同工程本地引用仍按确认结果迁移，旧会话页面缓存不合并。切到其他工程或控台后不修改新工程，也不报告虚假成功。
