## 本机 onPC 自动通路实测

- 安装版本 3.3.4.3；Lua `socket` 不可用。Telnet 30000 存在但需要有效登录，未继续猜测凭证。
- `gma.export_json` 写到数据目录 `temp`，该版本输出并非严格 JSON，不能直接 `JSON.parse`。
- `tools/ma2/tblink_bridge.lua` 以固定文件交换请求，严格数据帧，不执行请求中的 Lua；支持 PING、READ、APPLY。重复请求 ID 不再执行，重启不重放旧请求。
- 主进程 `Ma2OnpcBridge` 已提供类型化 IPC：序列化请求、15 秒超时且不重试、播放检查、绑定对象限制、写前备份、原版本核对、写后回读比较。
- `ma2-onpc-bridge.test.ts` 的显式本机测试已通过：读版本、读专属对象、自动备份、将事件时间 42 改为 43、回读、还原并比较完整 Timecode 报告。更严格回读核对和新版插件均已重新验收通过。
- 重载期间曾遇到旧试验定时器重复处理旧通道，写入结果被第二个实例报告为冲突。专属对象已独立回读并还原为 42；正式开发通道改为 `tblink_bridge_request.txt` / `tblink_bridge_response.txt`，并使用进程内 generation 排除重复插件实例。旧试验定时器不再收到新请求，在 onPC 重启时清除。
- onPC 会清除不存在的 Executor 引用，并重新解析 Cue 名称/step。因此仅通过时间修改不能代表 Cue/执行器/推杆往返已通过。
- 本机自动文件通路不等于实体控台局域网通路；自动同步界面、稳定对象映射和冲突处理尚未接入这条 IPC。

## 已落地代码

### 同步领域模型及事务

- `packages/schema/src/ma2-sync.ts`：规范化同步快照，严格校验版本、绑定、重复 ID、父级和循环引用。
- `packages/core/src/ma2-sync.ts`：三方差异；修改/删除冲突；明确选择双方版本；合并后引用完整性检查。
- `packages/core/src/ma2-sync-session.ts`：预览过期检查、备份、带预期版本的写入接口、回读确认、并发阻断、失败状态。
- 快照结构是内部模型，**不是假定的 MA2 原生协议**；三方合并服务尚未与本机 XML 桥和界面连通。
- 对象 ID 由后续绑定适配器维护；XML 节点 index/path 不能作为跨导入导出的稳定身份。
- 事务不会自动重试或自动回滚；不确定写入结果保留备份 ID 和 `mayHaveWritten`。
- 后续接入播放协调器时必须在同步期间锁住播放启动和本地编辑提交；仅检查 `isPlaying` 不能消除外部控台并发变化。适配器必须验证预期版本检查能力，做不到则不能启用生产写入。

### 实际 XML 样例检查

- `apps/desktop/src/main/link/ma2-timecode-xml.ts`：读取 Timecode、Track、SubTrack、Event、Cue / Executor 引用，保留原始属性。
- 文件 SHA-256 防止用旧预览修改新文件；时间修改仅在内存执行，保留其他 XML 节点。
- 支持 UTF-8 BOM；拒绝 DTD、实体声明、畸形 XML、重复索引和超过 32 MB 的输入。
- 3.7.0、3.3.4 XML 支持时间补丁，其他版本仅检查并警告；版本号不能证明该系列全部动作已兼容。
- 时间保持 XML 原始单位。安装目录 XSL 使用每秒 30 个单位换算显示，但尚未实测不同帧率与推杆曲线，未直接映射为应用毫秒。
- 本机 23 个历史文件、2,721 个事件通过读取及内存往返检查；未写回原文件。
- 未知 XML 扩展节点在时间补丁时保留；这不代表已理解所有动作，也不代表可无损导入完整 MA2 Show。

### 2026-09-11 MA2 反馈录制

录制生命周期进一步接入音频暂停、结束、定位及 MIDI 端口状态变化。暂停/定位截断已按下的音符，16ms 音乐位置采样在无后续 MIDI 时推进状态；断开停止并保存已有事件，清理计时器和监听器。轨道录制中被锁定时仍可点击结束录制。382 项单测通过，3 项环境测试跳过；模拟断开 Electron 用例验证退出录制、CC/MSC 保存及未释放音符收尾。定位边界采用最近采样位置，尚不承诺后台节流或硬件精度。

- 支持将 MSC GO/Goto（01）和 Go_Off（0B）反馈转换为可编辑 MA2 事件，接收 Exec.Page 及 Exec/NULL/Page 两种地址；小数 Cue 编号保留。
- MSC 不包含 Sequence 身份，因此仅使用当前录制轨道已有事件中的执行器与序列绑定。未绑定、同一执行器映射多个序列、Default Only 或其他指令保留完整原始消息，录制结束明确提示，禁止猜测序列。
- 380 项单测通过，3 项环境测试跳过；类型检查、Lint、构建通过。Electron 测试在真实音频播放时注入模拟 MSC，验证录成 Cue 37.200 / Exec 1.5 / Sequence 23 并自动保存。尚未接入实体控台，不代表反馈覆盖及硬件精度验收。
