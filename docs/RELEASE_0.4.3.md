# 0.4.3 · 修复旧节目缺少音频

0.4.2 只处理新拖入的视频，旧工程中已有的视频片段不会自动产生歌曲音频，因此点击这些节目仍提示需要添加音频。

本版在点击无音频节目卡片时恢复已有视频原声，保留时间线位置、源文件入点与裁剪范围；恢复完成后等待新播放控制器就绪，再执行正常预检和播放，无须第二次点击。已关闭或已分离的原声不会重新生成；恢复失败或工程切换会明确报告并取消写入。

验证记录：

- `pnpm verify`：705 项测试通过，32 项因设备或现场条件跳过；类型检查、Lint、构建与桌面产物校验通过。
- 隔离浏览器验证一次点击恢复音轨并使用新控制器播放，未调用缺少音频的旧控制器。
- 本机实际工程在备份后，从既有视频恢复一条 37.867 秒原声音轨并保存；点击节目进入播放状态、预检通过、MIDI 已连接且界面显示 MTC 发送中，验证后停止播放。
- 本机原开发实例仍运行旧后台，拒绝 `tracks` 参数；已完整重启。更新开发代码不能替代后台重启。

Windows x64 安装包未代码签名。下载私有仓库附件需要获授权的 GitHub 账号；此发布仍为手动下载安装，未迁移原有自动更新源。上述检查不代表 MA2 实体控台或整个现场系统已经实机验收。
