# MA2 中文素材分类 · 0.4.36

## 已证实的界面问题

此前把原生序列呈现为普通列表，未区分单步与多步，也没有进入序列后逐步试听的子菜单。原预览组件的 grid-row: 1 / -1 还让预览跨越整个工作台，步骤被下方时间线挡住；已限制到素材区并提供内部滚动。

## 实际改动

- 中文序列网格和单步、多步、目录待补全分类。原始编号与名称保留。
- 单步点击发送原 Cue 调用；多步点击只进入子菜单，不触发输出。每个子步骤可独立点击出灯。
- 完整序列从第一步开始、继续及关闭输出保留原生控台执行，未建立本地自动跟随计时器。
- 执行器式浏览和播放目标选择；选中步骤仅为浏览状态，实际活动步明确显示未回读。
- 日常入口：灯光工作台 → 控台灯光素材库；选中步骤可加入本地编排。
