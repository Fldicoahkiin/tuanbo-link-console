# 音频节拍辅助灯光 Cue

在编辑器点击「歌曲音频」，在属性栏的「自动节拍」中检测音乐，选择稀疏、标准或密集，然后应用标记。标记随工程保存；不会自动切分音频，也不会自动执行灯光。

音频片段顶部显示青色节拍小旗，点击可定位。开启时间线吸附后，双击放置灯光点、拖动已有灯光点、按 M 打点以及点击定位播放头都可以吸附节拍。吸附距离沿用工具栏设置，关闭吸附后可以自由定位。

检测先提取起音，再估计局部节奏周期，用动态规划选择节拍间隔连续的起音序列。密集保留主拍，标准约每两拍，稀疏约每四拍；按重音选择分组起点。不会把每个镲片和人声瞬态都视作主拍，也不会在静音里补点。它不是小节首拍识别；柔和、切分或大幅变速音乐仍需结合听感检查。

2026-09-14 实机参考：本机剪映专业版 10.9.0.14219，踩点菜单为「无／踩节拍 I／踩节拍 II」。同一段 37.95 秒音频，画面可见约 17／70 个标记。本项目保留用户指定三级，改进前为 33／98／227，改进后为 18／36／72。数量接近不等同于逐点完全一致。实际界面参考为深蓝音频块、蓝色底部波形、白色选中边框、两端裁剪和顶部青色小旗，不沿用旧版黄色圆点的假设。

参考方法：[librosa beat_track](https://librosa.org/doc/0.10.2/generated/librosa.beat.beat_track.html)、[Ellis 节拍跟踪研究](https://www.ee.columbia.edu/~dpwe/LabROSA/matlab/beat_simple/)。剪映内部算法未公开，本项目实现不是其源代码复刻。

手动音频剪辑位于折叠区，支持选择、分割、移动和裁剪。修改音频后需要重新检测节拍。

验证：合成鼓点及静音/持续音单测；独立 Electron 工程验证 FFmpeg 检测、三级密度、工程持久化、灯光点放置和拖动吸附、关闭吸附后的定位。未将这些离线测试视为 MA2 实体控台验收。
