# 开发版使用故障修复计划（2026-10-15）

## 目标与环境

修复用户反馈的 OBS 无法切场景、播放无反应和持续报错、本机 MA2 onPC 无法连接。以当前 Windows 开发版为对象，完成自动校验和本机实际链路验收。目标模式已启动。

工作区存在未提交的设置页、播放器及相关测试修改；保留原修改，不提交或推送。缺失的 TypeScript/frontend-design 技能不能视为已加载；遵循现有严格类型、分层及设计系统。

## 执行顺序

1. 收集当前进程、版本、日志和运行配置，复现失败，建立可追踪问题清单。
2. 修复 OBS 连接、场景切换和音频播放启动链路，检查暂停、恢复、停止、定位与切歌。
3. 修复本机 MA2 onPC 连接、登录和同步，覆盖断开、错误反馈、重新手动连接。
4. 对每个根因增加必要回归，完成类型、单测、Lint、构建和 Electron 功能测试。
5. 运行本机真实 OBS/onPC 联调，记录步骤、结果、证据和外部限制。验证当前运行程序确实使用修复后的构建。

## 验收原则

- 不以历史验收记录替代本轮测试，不把模拟或离线回归当作实机通过。
- OBS 不控制推流/录像，不删除用户已有来源；MA2 不修改 Cue 内部灯具参数。
- 工程修改经 Command；外部错误须明确展示和记录，不用自动重试掩盖故障。
- 无法完成的现场验收明确保持未完成，不提前宣称所有功能通过。
