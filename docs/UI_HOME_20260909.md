# 首页与界面优化 · 0.3.1

按用户要求，工程与节目单仍是唯一主控页，保留单击歌曲播放和 P1 跟随模式。视觉参考 Apple Human Interface Guidelines 的内容层级与侧栏原则，采用连续的歌曲列表、留白、低对比度分隔线和克制的选中反馈，移除首页大面积蓝色卡片和重复框线。

播放控制与音量/连播分开排列。右侧属性区提供直接编排素材与 Cue、替换音频入口；列表显示时长、素材数量、Cue 数与运行状态。顶部显示真实 OBS 连接状态，音乐与灯光连接按需展开。无工程时提供新建/打开入口与简短引导。

已修复最小窗口下窗口控制遮挡“添加节目”的问题。桌面测试新增标题栏遮挡及关键操作位于主视口内的检查，覆盖直接打开素材编排入口。实机验证歌曲单击播放、暂停、继续、停止及停止后编辑恢复；OBS 连接正常，renderer 无异常。

本次主要修改 UI，不改变音频时钟、MIDI 输出、OBS 动作执行或原始素材处理。0.3.0 的真实十节目连续播放与断线恢复记录仍作为既有运行逻辑证据，不将其称为本版新增十首实测。

设计参考：https://developer.apple.com/design/human-interface-guidelines/sidebars
