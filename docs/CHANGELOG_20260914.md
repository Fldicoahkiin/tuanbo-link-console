# 2026-09-14 源码整理与界面变更

## 首页与节目属性

- 编辑节目位于右下方，与顶部计时面板使用相同列宽。
- 展开或收起属性区不改变节目卡片的位置和尺寸；点击列表空白可收起。
- 节目名称支持 Enter 保存、失焦保存、Esc 取消，撤销后名称输入同步恢复；支持中文输入法组合输入。
- 停止按钮增加文字、底色和边框；临时音量滑块加长。

## 音乐与灯光辅助

- 恢复顶部波形和播放控件，实时频谱位于中间。
- 计时面板采用 P1 风格的七段数字、正倒计时和双声道电平；显示输出采样率与 MTC 状态。
- 修复通用 SVG 图标高度导致整块计时器缩至 17px 的样式冲突。
- 修复音频监测共享音轨被组件清理关闭的问题；适配器返回独立克隆，释放失效监测节点。
- 修复播放状态提前发布而监测接口因 audio.paused 拒绝订阅的时序问题；暂停与等待状态明确显示，错误提示不挤压计时内容。
- 三级节拍检测用于灯光 Cue 标记与吸附，不切分正式音频。算法和第三方参考的边界见 AUDIO_BEAT_LIGHTING.md。
