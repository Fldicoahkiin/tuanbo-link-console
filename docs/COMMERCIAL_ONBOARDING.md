## 1. 已备案域名还要做什么

[工信部备案查询](https://beian.miit.gov.cn/) · [腾讯云备案控制台](https://console.cloud.tencent.com/beian)

本次已在腾讯云控制台读取：`jinhefilm.com` 为公司主体、状态正常、已接入腾讯云且关联目标实例；原服务名称为金河分镜。新增子域名无需重复接入备案，但新增独立产品的服务信息是否调整仍需核对。不能根据域名解析在 Cloudflare 就认定接入备案在 Cloudflare；DNS 托管、注册商和大陆服务器备案接入商是不同事项。

- 若顶级域名已有有效备案且已接入腾讯云，通常不需要给每一个下级子域名单独申请 ICP 备案。腾讯云官方明确：顶级域名备案后，三级、四级域名可以使用。
- 若域名备案在其他接入商，使用腾讯云大陆服务器需要办理腾讯云接入备案。并非重做一遍主办单位首次备案，也不要先注销原备案；已有站点还在其他接入商时，按实际接入关系处理。
- 若备案是个人或其他主体，不能直接认定其适用于本公司的软件经营。核对是否应变更主体或提交商户要求的授权材料。不要在未核对之前提交公司进件。
- 若新的独立网站/服务内容、网站名称、负责人或主体信息发生变化，应让腾讯云备案审核根据现有记录确定是否变更或新增网站信息。“子域名不用逐个备案”不等于所有新业务手续均豁免。
- ICP 备案和经营许可、公安联网备案、商户审核是不同事项。是否涉及增值电信业务许可须根据实际业务核对，不能仅因软件收费就直接断定必须办某一许可证，也不能反过来一律排除。

依据：[腾讯云域名备案规则](https://cloud.tencent.com/document/product/243/18905)、[下级域名与接入要求](https://cloud.tencent.com/document/api/243/19630)、[接入备案说明](https://cloud.tencent.com/document/product/243/43878)。

对外网站实际开通后，再按属地要求完成/变更公安联网备案；腾讯云指引列出开通访问后 30 日内办理要求。入口：[全国互联网安全管理服务平台](https://beian.mps.gov.cn/)，办理前核对官网当前入口与属地要求，不能把旧项目备案号直接贴到新站。[腾讯云公安联网备案说明](https://cloud.tencent.com/document/product/243/19616)。

## 5. 无账号自动交付怎么落地

```text
服务端商品/含税价格 → 创建订单与随机查询凭据 → 支付二维码/跳转
   → 渠道回调验签 + 主动查单补偿 → 核对商户/币种/金额/流水
   → 原子记录已支付 + 唯一交易约束 + 一次发码 + 交付任务
   → 客户用购买凭据查询并领取激活码（可另发交付邮件）
   → 客户机输入码 → 首次绑定机器 → 返回签名凭证（每次重新启动仍须联网验证）
```

客户不注册，不需要邮箱密码登录；但仍需要不可猜的订单查询凭据或一次性交付凭据。订单号、付款截图、机器码、已知邮箱都不能单独成为领取任意激活码的授权。交付失败可重新领取已有码，不能再扣一次钱或重新生成另一批码。

当前支付宝通知验签、运营签名付款链接、主动查单与凭据领取已部署，收款配置仍关闭；商品目录与价格版本、自助下单已部署并验证关闭状态；桌面购买与同单恢复/领取已本地实现，尚未发布安装包。后续继续完成微信下单与回调、失败交付任务、跨机客户找回、退款累计金额与售后审计、对账导出和发票接口。不能直接将 `/admin/orders/:id/fulfill` 暴露给渠道或客户端。

验收必须覆盖重复/乱序通知、错商户/错 AppID/错金额/错币种、签名错误、通知响应丢失、数据库事务失败、交付失败、付款后刷新、跨客户查询、重复领码、企业一单多码。支付订单创建和交付可以自动处理，实际金融签约、用户真实付款及争议决定仍由本人承担。

## 6. 自动开票办理与实现

入口：[四川电子税务局](https://etax.sichuan.chinatax.gov.cn/)。公司在成都，使用四川的权限和规则；服务器在上海不改变公司主管税务机关。

### 先核实公司开票资格

本轮已完成企业登录并只读核查，数电票业务页显示可用额度，开票票类菜单同时列出专用和普通发票；未开具发票、未提交税务申请。账户中心的“纳税人资格”显示“待补充”，本人完成一般纳税人资格查询后返回“暂无数据”，当前未获得一般纳税人登记证据，不能单凭空结果作最终资格认定；首页的小规模申报快捷入口也不能替代资格记录。私人办税结果、额度和税号不复制进项目，后续在授权的公司财务档案中保存。

办理时继续读取：

1. 增值税纳税人资格（一般/小规模）、生效日与税费种；不按营业执照上的有限公司或主观印象推定。
2. 发票票种及数电普票/专票权限、剩余开票额度、开票员身份、是否有待处理风险提示。
3. 本产品的实际交易性质、发票项目、税收分类编码与适用税率/征收率，由办税记录和专业核对确定；软件授权、软件产品销售和技术服务不可为了方便混填一个项目。
4. 原有发票申请是否已经办结，以结果页面为准；能查看/接收发票不代表能开具或有 API 权限。

### 接口路线

优先询价支持四川企业数电票的服务商方案；例如[发票通官方入口](https://www.fapiao.com/)提供数电票与 API 产品介绍，可作为询价对象，不代表已选购、已验证四川权限或已经合作。也可比较百望的官方方案。不要把名字相近的第三方站点当成上述厂商。

自行直连乐企需要符合所在地接入条件、申请、能力订阅和联调测试，普通数电票可用不代表 API 权限。2026-09-28 已读取[渠县人民政府网站发布的四川省税务局规范指引 PDF](https://www.quxian.gov.cn/uploadfile/1/Attachment/071e9c5f95.pdf)，第 2–3 页列出直连单位纳税信用 A/B、企业及同时申请使用企业上一年度收入合计 5000 万元以上、申请前 12 个月开受票合计至少 5 万份等条件。文件还列有单位关系、技术安全与审核要求，不能只满足其中一项便宣称可接入。

该 PDF 可证明公开指引内容；本次未核实其发布/修订生效时间及截至今日是否有新口径，也未取得本公司符合门槛的资料。先通过四川征纳互动/12366核实当前适用规则，尤其是新设企业、M 级信用和小票量的软件销售企业是否有适用的合规接入方式。初步实施方向仍是评估服务商 API；服务商不能以本公司并不具备的集团关系代办“乐企自用”。申请前索取其实际接入路径、企业授权要求和四川适用依据。

### 开票自动化的数据流

```text
已核实支付订单 + 客户有效开票资料
 → 校验可开票金额、销售方税号、商品税收编码与税率
 → 独立开票申请（业务唯一号）→ 开票服务商受理
 → 异步查询/回调确认真实票号与状态 → 保存原始电子票据及订单关联
 → 客户下载/自愿选择邮件交付 → 发票与支付账单对账
```

开票申请 `pending`、服务商 `accepted` 和实际 `issued` 必须分开。请求超时先查原业务单，不能直接换编号重开；退货退款进入独立红冲流程，不能删除原票或把退款 API 成功当作红冲成功。尚未开通渠道时明确显示“待处理/未接入”，不能生成 PDF 冒充税务发票。

个人购买按需要开具个人抬头发票；企业抬头与税号要校验，专票另按适用要求收集信息。除必要资料外不额外收集身份证。发票申请和交付可以在桌面购买流程/订单凭据页面完成，不要求建立账号系统。

红冲可能依购方用途/入账确认状态需要对方确认，不能承诺所有退款均可立即自动红冲。[税务总局红字数电票说明](https://www.chinatax.gov.cn/chinatax/n810356/n3010387/c5236346/content.html)。
