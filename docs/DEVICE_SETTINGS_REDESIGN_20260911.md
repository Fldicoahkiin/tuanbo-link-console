# 设备连接设置重构验收（2026-09-11）

本次只重组设置界面与交互，继续使用既有 IPC、MA2 服务和工程命令，没有修改工程格式或网络协议。

## 页面分工

- 设备连接：MA2 目标、连接方式、账号、自动连接；OBS 地址与密码；音乐监听、时间码、灯光输出及录制输入。P1 跟随时显示对应时间码输入。
- 灯光 → 节目同步：读取、创建 Timecode、导入节目、执行器绑定、差异预览、冲突选择、同步与回读。没有灯光轨道也能导入。
- 维护与诊断：MA2 插件导出、接口检查、远程与监视端口、MSC 地址、本机程序和日志。视频原声偏好移入播放设置。

设备页为纵向平铺表单，标签 120px，IP 240px，账号密码 300px，设备下拉框不超过 360px；取消步骤条、并列卡片、说明栏和全局保存。

## 状态与保存

- 设置工作区保留连接草稿，跨页不会清除尚未提交的密码；换控台或修改地址/用户名清空上一目标的密码草稿。
- MA2 保存与连接区分。每次确认连接后自动做一次只读接口检查和插件 PING，登录成功不等于插件可用或同步成功。
- OBS 保存仅提交 WebSocket 地址与 OBS 密码，不提交尚未保存的程序维护字段。MIDI 选择独立自动保存并短暂显示结果。
- 切换目标或节目使旧预览失效；同步仍使用原有复核、备份、写入、回读与工程命令。播放期间禁用目标修改与同步写入。
- 密码继续使用既有安全存储，不写入工程文件；连接草稿中的密码仅留在内存。
