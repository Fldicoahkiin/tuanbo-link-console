# 虚拟 MIDI 通道准备

2026-09-14：设备 → 音频与 MIDI → 虚拟 MIDI 通道（loopMIDI）。

- 检测本机运行进程、卸载注册表和标准安装目录，区分未找到、已安装和正在运行。
- “启动／连接”复用已运行实例；新启动按精确路径和 PID 确认。并发请求合并，失败不自动重试，也不关闭任何 loopMIDI 实例。
- “随联动台启动”存入本机集成档案 `loopMidi.autoStart`，旧档案默认关闭；开启后在桌面初始化、一键连接和 P1 启动流程中准备通道。工程文件不增加机器配置。
- “重新检测”同时更新 MIDI 端口，按端口名、方向及唯一性显示可用状态。MIDI 系统申请 5 秒超时后明确报错，允许操作员再次检测。
- 未找到时可打开固定官网地址下载安装。首次仍需在 loopMIDI 建立端口，并在通信两端选择同一端口。自定义目录无法发现时，先手动启动再检测；当前不保存自定义 loopMIDI 路径。
- 内部音乐播放及 OBS 控制不要求安装 loopMIDI。没有启用自启动时不会强制启动它。

## 交付边界

本次提供外部 loopMIDI 的准备与引导，没有捆绑安装包、自动安装驱动或通过 SDK 创建端口。完全内置虚拟端口需要另外落实驱动授权与部署。官方资料：

- https://www.tobias-erichsen.de/software/loopmidi.html
- https://www.tobias-erichsen.de/software/virtualmidi/virtualmidi-sdk.html
