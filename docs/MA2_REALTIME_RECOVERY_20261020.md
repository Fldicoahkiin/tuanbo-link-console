# MA2 实时同步重构进度

记录开始于 2026-10-20，0.4.57 本地交付验收于 2026-10-21 完成，完整安装包已生成并通过包内启动验证。用户要求优先解决同步、默认开启，编辑不能被网络与回读问题阻断；明确停止查看远程电脑后，本轮只检查源码、本地 Electron 和隔离 onPC。

## 已实施

- 顶部同步入口与歌曲序列同步使用同一创建策略。首次默认开启，用户主动暂停会保存；网络歌曲不再隐式进入 Timecode 9999 自动创建流程。
- 每首歌曲分别维护待同步、回读、已确认和暂停状态；已有绑定固定在原序列、页码、格位，新歌使用工程配置的默认页（缺省 1000）与可用空序列。
- 编辑、本地自动保存与控台同步分离。已有保存路径的灯光工程在连续编辑结束后自动保存；保存队列保持调用顺序，旧保存完成不能清除后续修改的 dirty 状态。磁盘失败真实展示并记录。
- 意外网络断开恢复原连接；主动断开不自动连接，不重放播放命令。恢复后先读取对象、基线与持久化创建记录，不直接重发上一次操作。
- 新建序列先记录创建意图，使用 MA2 内部 Copy 合成各步，避免把所有灯具参数重复上传。已确认创建记录可恢复丢失的本地绑定；部分创建记录可核对已完成/未完成步骤后在原位置继续。
- 同步中开始播放会保留待同步状态，停止后再核对；暂停会取消后续尚未发送的步骤。主进程请求具备取消及无进展超时，不因一笔持续有进展的大任务超过固定总时长而打断。
- 回读检查在控台比较完整原生导出；内容不变时不反复传回整曲 XML。XML 解析按来源序列和批量 Cue 复用，降低重复解析开销。
- Lua 脚本中的 `$`、引号、反斜线等字符采用十六进制传输，防止先被 MA2 命令解释器处理而失去确认。
- 软件改名与控台编灯按字段合并；同一字段冲突、已改变的删除清单和不同 Show 不自动覆盖，其他编辑、保存及其他歌曲仍可继续。
- 同字段冲突返回原值、软件值、控台值与核对令牌，可逐项选择采用软件或控台；旧令牌不覆盖已经再次变化的控台。未决字段保留旧基线，其他 Cue 可继续写入和回读。
- 中断记录覆盖首次创建和已有绑定更新。创建期间新增、删点、清空、替换或改名会在原位置续传；已写入但丢回包的内容和部分改名通过写前快照与阶段指纹核对，避免重复写入和误报冲突。写入后撤销替换按写前快照恢复，不吞掉 Undo。
- 桥升级或重启后先核对同一 endpoint、Show 和版本的序列目录，再更新工程中的会话 generation 并续接；不同 Show 保留原工程。只核对目录不冒充重新读取了所有灯具数据。播放时不启动此扫描。
- 切换工程、MIDI 模式、主动暂停或重新启动同曲同步会话后，迟到结果不写入当前工程。已解除分配的歌曲保留 Sequence，不自动重新分配执行器。
- 已绑定歌曲可清空为 0 个时间线点，控台删除逐项进入现有核对清单。确认后通过空序列快照保留原 Sequence 和执行器；不会执行导致 MA2 自动解除分配的“删除最后一个 Cue”。原生 Part 0 名称与重复 Cue 名称属性使用同一指纹含义，避免清单令牌在内容未变时失效。
- 数字阶段进度显示在左下任务区；保存、撤销、重做不因正在同步而禁用。
- 控台页面已按参考照片呈现 Button / Fader / Button 三层紧凑按键，保留各层页码切换及输入；不显示竖推杆或额外登录入口，支持拖动换位与右键删除执行器分配。
- 顶部同步详情和本曲序列面板已接入逐项冲突决议，可看到软件值、控台值并选择保留哪边。歌曲面板中已列入删除清单的 `cue-deletion` 不再重复显示冲突卡片，其他字段冲突照常显示；顶部待核对详情保留删除信息，删除仍须明确确认。

用户本轮明确要求连接恢复后继续同步，该授权仅用于上述连接恢复、状态核对与可核实的续传，不推广到排练动作失败自动重放、切换计时来源或未核对的删除。
