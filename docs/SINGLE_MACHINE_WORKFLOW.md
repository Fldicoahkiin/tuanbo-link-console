# 团播联动台单机闭环实施基线

## 唯一现场链路

```text
P1 正式音乐与既有声光
  ├─ MTC → 团播联动台 → 摄像头/视频/OBS/MIDI/灯光 Cue
  └─ 正式音乐音频 ─────────────────────────────┐
                                                ↓
OBS 摄像头 + 联动台受管视频（含内嵌音频）→ 正式画面与正式音频
                                                ↓
抖音直播伴侣只采集 OBS → 登录、直播间、推流
```

联动台不是媒体服务器。编辑端预览只帮助操作员编排；现场真正采用的每一帧视频和每一路音频都由 OBS 输出。P1 不接收摄像头，也不播放联动台视频。

## OBS 受管输出

- 固定场景名为“团播联动台输出”。首次设置由操作员明确点击初始化；联动台不得静默修改其他场景。
- 联动台创建的输入和场景项使用可识别固定前缀，并保存工程、图层和素材的稳定 ID。名称冲突、类型冲突或所有权无法确认时立即阻断。
- 摄像头、采集卡、显示器、窗口和已有 OBS 场景仍由用户在 OBS 中创建。联动台只把选中的已有来源作为场景项加入受管输出，不重新打开设备。
- 本地视频使用 OBS `ffmpeg_source`，图片使用 OBS `image_source`。视频内嵌音频默认进入 OBS；操作员可对具体片段显式静音。
- 视觉图层第一行是最上层。发布时把工程图层顺序确定性映射为 OBS scene item index，同层片段不允许时间重叠。
- 工程默认输出画布为 1080×1920（9:16），可显式切换为 1920×1080（16:9）。Cue 舞台使用工程画布；OBS 基础画布尺寸不一致时阻断现场预检。
- 片段开始顺序固定为：验证文件 → 更新媒体输入 → 设置变换与音频 → 定位素材入点 → 启用场景项 → 重新开始播放。
- 片段结束顺序固定为：停止媒体输入 → 禁用场景项。任一步失败都记录具体请求；不自动切换到 Electron 预览输出。

## P1 与时间码

- P1 播放正式音乐并发送真实 MTC。自动模式为每首歌分配明确的原生时间码区间，换算为节目内零点。
- 本机 P1 1.14.2 已通过可回滚兼容修复连接 loopMIDI，无需外接硬件；只有实际收到时间码才显示已接通。
- 自动模式打开保存的工程后监听，点击 P1 歌曲即自动匹配并执行；手动模式仍可选择节目并“启动并待命”。完整说明见 [P1_AUTO_FOLLOW.md](P1_AUTO_FOLLOW.md)。
- 正式播放链路只要求 P1→联动台的 MTC 输入端口；只有工程 Cue 确实向外发送 MIDI 时才要求对应输出端口。
- 时间线 Cue 与媒体片段都采用上一有效帧小于事件帧且事件帧小于等于当前有效帧的跨越判定。
- 500ms 丢码或异常跳变冻结自动动作；自动模式允许 P1 同位置继续、明确区间切歌和从头重播。未知区间或中途接入必须从头重新播放。

## 正式音频

- P1 正式音乐必须通过现场既有声卡、应用音频采集或经操作员确认的路由进入 OBS；集成档案显式选择承载 P1 音乐的 OBS 输入，联动台验证该输入存在、支持音频状态读取且未静音，不擅自改系统音频设备。
- 视频内嵌音频由 OBS 媒体源直接解码，避免 Electron 预览解码能力影响正式播放。
- 同一时刻 P1 音乐与视频内嵌音频是否同时出声由片段显式配置，不做自动 ducking 或隐式混音。

## 直播伴侣边界

- 直播伴侣采集 OBS 的配置由操作员在直播端完成一次并人工签收。
- 联动台不检测、不启动、不关闭、不预检也不操作直播伴侣；直播伴侣是否运行不会影响 OBS/P1 联动。

## 实施顺序

1. 冻结工程字段、受管 OBS 所有权、媒体开始/结束事件和预检规则。
2. 实现 OBS 受管场景初始化、素材发布、摄像头引用、层序、变换、内嵌音频和明确清理。
3. 把媒体片段开始/结束编译进与 Cue 相同的 MTC 跨越执行链，补齐失败策略和日志。
4. 完成 P1 MTC 待命流程、端口实测、工程同步和曲目人工匹配。
5. 收敛剪辑式时间线、工程自动保存、右键、吸附、缩放和画布操作。
6. 完成预检、诊断、NSIS、发布清单和真实现场验收。

## 完成定义

只有以下项目同时通过才完成目标：

- 固定版本下 install、typecheck、test、lint、build、verify、Electron E2E 和 Windows release 全部通过。
- 一个节目至少包含五个 Cue；P1 从零 MTC 能驱动摄像头切换、本地视频、视频内嵌音频、OBS 动作和灯光/MIDI。
- 断开 MTC 后自动动作冻结，恢复必须人工确认；OBS 动作失败符合排练阻断/直播继续规则。
- OBS 持续输出完整画音，直播伴侣持续采集 OBS，联动台不直接输出 Program。
- 工程保存重开一致，诊断包不含凭证，退出后不误关外部原有进程。
- Windows 安装包可在独立账户安装、覆盖、启动、退出和卸载，无残留进程。
