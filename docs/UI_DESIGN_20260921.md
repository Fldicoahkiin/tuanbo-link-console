## 范围与设计决定

基于当前有未提交修改的工作区实施，保留原有工程、运行时、OBS/MIDI 和灯光编辑功能。未提交或推送 Git。

技术栈：Electron 39、React 18、TypeScript、原生 CSS、lucide-react。参考项目 AGENTS.md、docs/DESIGN_BASELINE.md；桌面窗口基线 1540×960，最低 1180×720。

- `appearance.css` 持有深浅主题和语义字号。12px 为辅助文字、13px 为紧凑控件、14px 为正文；时间轴的坐标和采样位置不随视觉规范改变。
- `interface.css` 负责跨工作区的控件、表面、焦点、模态层、通知和缩放适配，最后加载。页面 CSS 保持几何与业务状态的所有权。
- 全局统一侧栏选中状态、按钮层级、输入边界、面板圆角与留白。状态采用语义颜色，不把正常未发送 MTC 标成错误红色。
- 播放监测使用等宽数字，保留百分之一秒、正计时、倒计时、总时长、采样率、双声道电平和 MTC 状态，未变更计时来源。
- 灯光效果库、工具栏、事件列表、标尺、浮动菜单接入深浅主题。真实预览画布与波形色保持其内容语义。
- 所有 CSS hover 规则按输入能力限定；组合选择器的键盘焦点和选中分支仍在媒体查询之外。短按反馈仅在允许动态效果时启用；时间线拖动不增加延时或装饰动画。
- 原生 ModalSurface 用于新建工程、播放列表新增/改名/删除、OBS 来源创建，浏览器管理背景 inert、焦点约束及 Esc。工程创建失败在弹窗内显示；OBS 取消仍执行既有来源清理流程。
- 错误通知保留至用户关闭，并提供可访问名称；普通通知为 polite 状态区。通知容器空白区域不拦截鼠标。
- 空素材库提供添加入口，搜索/分类无结果提供清除筛选。列表名称保留完整 title，导航暴露当前状态。
- mobile-native 应用与 Windows 触控兼容的按下反馈、hover 能力检测、滚动边界规则。不将手机导航、安全区或 iOS 字号限制直接强加到桌面工作台。

测试不仅验证截图生成，还验证主视口边界、设置可滚动性、真实键盘焦点约束/恢复、主题持久化、播放列表增删改、灯光拖放/撤销/保存及快捷键。
