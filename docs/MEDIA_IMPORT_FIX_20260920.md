# 0.4.6 媒体导入现场故障

## 已确认与修复

- 30 fps 等帧时间换算产生小数毫秒，视频原声进入整数 `AudioSegment` 契约时失败。新视频导入及旧视频原声恢复统一在音频边界转换为整数毫秒，原视频仍保留帧时间码。
- 视频容器时长可能长于实际音轨。旧导入将容器时长直接记为提取后的 WAV 时长，后续 PCM 合成读取越界。现在从提取结果的数据块计算真实采样时长；独立音轨使用实际长度，视频长度不变。
- WAV 只读取块头，不整段载入内存，不增加常驻进程。没有放宽损坏音频与越界读取检查。
- P1 导入保留声明时长检查，明确拒绝用短音轨悄悄缩短节目；无效裁剪报错增加文件路径、cut_start、cut_end，便于现场判断。
