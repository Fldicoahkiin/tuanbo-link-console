# 时间线自动收起与下拖新建

2026-09-14：媒体 / OBS Cue 时间线只显示有内容的视觉轨道。删除或移走最后一个片段后，空轨道自动从布局收起；撤销恢复内容时轨道重新出现。工程中的轨道配置保留，以免丢失显隐、锁定和排序信息。

拖动已有视频或 OBS 场景到时间线底部空白区域时显示“松开新建时间线”，松开后在底部新建视觉轨道并放入内容。素材库拖放同样支持底部新建和已有轨道落点。锁定内容不可移动；Esc、失焦或 pointercancel 取消拖动，不创建轨道。

新建轨道与放入 / 移动内容作为单个 LinkCommand 执行，一次撤销可还原。音频与灯光专用轨道保留原有编辑规则。

验证：`workspace-actions.test.ts` 覆盖底部新建、锁定、一次撤销与重做；`scripts/check-timeline-auto-lanes.mjs` 在本地开发服务验证实际指针拖拽、空轨道收起、取消、删除和素材库落点；`scripts/check-timeline-transfer.mjs` 回归现有跨轨移动。
