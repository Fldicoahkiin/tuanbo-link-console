# 0.3.0 工程主控验收（2026-09-09）

## 本次交付

“工程与节目单”是唯一主控页面，沿用 P1 风格的播放列表、蓝色节目卡片、音频属性和正/倒计时。没有独立播放页面。单击歌曲播放，右键进入编排；暂停、继续、停止、重播、上一首、下一首、连播、循环、音量与淡入淡出在同页操作。音乐与灯光连接可在同页展开。

工程可显式选择内部主控或 P1 跟随。内部主控按实际音频播放位置驱动 OBS 素材和 MIDI 时间码。保留原有 P1 纯软件连接，不依赖外接 MIDI 硬件。MA2 onPC 接收使用本机 Default App Loopback (A) 输出 → (B) 输入，TC Slot 2。

- 44 个测试文件、287 项单元测试通过；类型检查、Lint、桌面构建与发布产物检查通过。
- 17 项 Electron 桌面流程测试通过，包括空工程导入音乐、模式保存/恢复、单实例、最小窗口布局、Cue 编排、关闭保护。
- 合并页面真实连续播放：10 个节目，每首约 8 秒，10 次素材启动、10 次停止，失败 0，renderer 错误 0。实际收到 9,664 条四分之一帧 MIDI 消息、10 条全帧消息，八种分片齐全；MA2 onPC 第 2 时间码槽现场截图确认推进。证据 internal-integrated-ten.json、internal-ma2.png。
- 真实 OBS WebSocket 断线：音乐停止、位置冻结、显示清理失败；重连后点击停止清理，再点击第 3 首成功播放。暂停拖动到约 3.1 秒保持暂停，继续及停止成功，停止后编辑恢复。证据 internal-recovery.json；其中故障注入期间的失败日志属于预期。
- 播放时工程主控页保持可见，名称、工程参数与 Cue 编辑锁定。切歌和传输控制可用。
- 安装包首次安装、同版本覆盖、启动、正常关闭、卸载检查见 installer.log；检查针对隔离安装目录。
- 演示工程 1 个原视频及 3 个音频引用逐一核对 SHA-256，与工程记录一致。素材不做二次有损视频压缩；正式显示由 OBS 直接读取原文件。

## 实际边界

十个短节目重复使用现有视频，未拿到用户十首真实演出素材；不能代替十种不同高码率素材、多图层或数小时直播压力验证。现有视频为 448×960，放大到 1080×1920 不会增加原有细节。直播平台与 OBS 编码仍会影响最终画质。

没有实体控台：仅验证 MA2 onPC 软件接收，没有验证实体灯具或 DMX。未启动直播、录制或平台推流，也未宣称复制 P1 全部专有功能。顺序切歌包含预检与准备间隔，非无缝音频拼接。当前内部时间码支持 24、25、30 fps，29.97df 明确阻止。工程总时间码区间小于 24 小时。

连接状态不能替代实际接收：新建 Tuanbo MA2 虚拟端口在本机没有真实回送，交付使用实测成功的系统 A→B 回环端口。故障不会自动改用另一主控或无音频计时。
