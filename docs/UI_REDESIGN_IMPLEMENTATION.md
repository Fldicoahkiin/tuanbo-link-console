# UI 结构重构实施记录

日期：2026-09-21。构建版本：0.4.10。

本次交付是可运行、已打包的核心工作区结构重构。它在前一轮主题和公共控件优化之上，调整了页面结构、空间分配和操作入口；完整计划中的增强项及现场验收仍有待完成事项，详见文末。

## 实施与能力对应

| 范围 | 新结构与保留的入口 |
| --- | --- |
| 全局 | 按用户最新要求恢复左侧纵向主菜单；菜单下方展示当前工作区的播放列表、素材、灯光节目或设置目录。保留工程操作、保存状态和原生窗口控制。 |
| 节目单 | 当前节目与播放控制置于主区域，右侧集中时间监看；频谱按需展开。默认紧凑列表，提供卡片切换、搜索和新建节目。属性默认收起，可从标题栏或节目行打开。原单击/双击播放习惯、播放列表和节目管理保留。 |
| 播放监看 | 停止时总时长对应选中音频；播放时对应实际播放对象。MTC 发送状态要求已有发送位置证据，避免未发送时显示发送中。P1 跟随与内部主控保持显式选择。 |
| 视频编辑器 | 左侧素材、中间画布、下方时间线、右侧上下文属性。属性可收起，选择新对象后重新展开；分隔条支持拖动及方向键。低功率、OBS 预览和已有对象编辑入口保留。 |
| 时间线 | 限制初始高度占比，避免挤压画布。Cue 卡点编辑改为原生模态顶层，修复调整布局后保存按钮被工具栏遮挡的问题。原有拖动、快捷键与命令编辑链路保留。 |
| 灯光 | 工具栏置顶，素材库与编排属性左右分区，下方保留波形及时间线。搜索、分类、导入、管理、读取及同步入口保留；保存动作使用明确文字。长节目名省略并提供完整标题。 |
| 设置 | 4 组、14 页使用同一左侧目录与内容区，移除重复占宽的独立目录列，保留所有配置入口。 |
| 辅助界面 | 延续统一新建、列表管理、来源选择等模态结构；日志组件采用原生模态、级别筛选、详情展开和弹窗内错误。遵循既有产品决定，不重新增加已移除的诊断日志入口。 |

未修改工程 schema、正式输出归属、断线策略或设备控制边界。未提交、推送或覆盖用户已有修改。

## 样式归属

- `appearance.css`：主题、语义色与字号。
- `home-layout.css`：应用框架、主导航和节目单结构。
- `lighting-workbench-appearance.css`：灯光工具栏、库区及编排区布局。
- `interface.css`：公共控件、模态、焦点及公共适配。
- 各业务工作区样式：轨道、画布、选择和业务状态。

迁移对应结构时移除了冲突的旧布局规则，没有新增末尾覆盖样式文件；这不代表仓库内所有历史 CSS 已完成清理。

## Codex 风格灰阶主题 · 0.4.11

按用户最新反馈，以 Codex 的中性灰阶和轻量边界为方向，保持左侧纵向菜单。不是对 Codex 客户端逐像素复刻。

- 深色采用中性炭灰主区域、稍深侧栏、灰色选中状态和浅色主按钮；浅色采用白色主区域、浅灰侧栏、深色主按钮。
- 移除节目行的浮起阴影、蓝色选中描边、标题栏硬分隔线和侧栏边线。节目列表改为连续内容，选中时显示柔和背景。
- 控件、面板、弹窗分别使用 8/14/16px 圆角；编辑器属性区、灯光素材区接入同一表面与边缘规范。
- 修正黑白按钮的前景配对，吸附按钮和灯光节目选中使用语义灰阶；警告、错误、连接状态与时间线业务色保留。
- 仅调整样式和发布版本，没有修改媒体控制、工程数据或设备行为。

两项 Electron 检查通过：真实数据/长节目/应用缩放；全工作区深浅主题、三个窗口尺寸、模态焦点与文本对比。截图和颜色测量保存在 `apps/desktop/test-results-neutral-final/`。这次的自动化检查不能代替用户对视觉风格的最终判断。
