# 0.4.2 · 独立音轨与播放修复

- 更新应用、任务栏及安装程序图标：石墨黑底、银白联动符号。
- 拖入视频自动增加独立原声音轨，保留已有歌曲音频；支持多条音轨、移动、裁剪、分割、删除和撤销。
- 音轨按真实 PCM 位置混合，避免同一份视频原声重复输出；无声视频明确提示并保留画面。
- 修复其他未完成节目缺少音频时，阻断当前正常节目播放的问题。内部主控仅预检当前节目，P1 全工程预检保留。
- 软件更新页显示当前版本号。

验证：`pnpm verify` 通过，700 项测试通过、32 项因设备或现场前置条件跳过；类型检查、Lint、生产构建及桌面产物检查通过。真实 FFmpeg 验证重叠双声道混音与时间线间隙；隔离浏览器工程验证双轨行对齐、选轨、分割、移动、删除与撤销。

Windows x64 安装程序未代码签名。下载私有仓库附件需要登录获授权的 GitHub 账号。此版本通过本仓库 Release 手动下载安装，原有自动更新源未迁移。

音频编辑前请停止播放。多音轨工程需要使用支持多音轨的新版本；旧版会拒绝其时间线字段。新增功能不代表 MA2 实体控台或现场 OBS 链路已完成实机验收。
