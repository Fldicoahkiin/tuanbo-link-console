# 软件图标

图标以联动关系为主题：石墨黑圆角底板、银白连接符号，保持单色、高对比和清楚的负空间。图形不含文字、发光或设备细节，便于任务栏和快捷方式识别。

- 矢量母版：`apps/desktop/build/icon.svg`，24 × 24 逻辑网格。
- PNG：1024 × 1024，透明外边缘。
- Windows ICO：16、24、32、48、64、128、256 像素独立渲染。
- ICNS：同步导出 16 至 1024 像素资源；本项目的正式目标平台仍为 Windows。
- 主窗口、可执行文件和安装程序继续使用现有 `build/icon.ico` 配置。

重新导出（需安装开发依赖及 Microsoft Edge）：

```powershell
node scripts/export-app-icon.mjs
```

导出直接从 SVG 渲染各个尺寸，不将低分辨率图像放大。更换文件不会改变已经发布的安装包；需重新打包安装后才会替换已安装程序的图标。Windows 对已有快捷方式可能保留图标缓存。
