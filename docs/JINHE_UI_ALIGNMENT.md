只读参考 `https://github.com/JinHe9527/jinhe-storyboard` 的 main，提交 `5c583009ae404fb8eac8ef0b13fab742aed5b6aa`。用户给出的 macOS 本地路径在当前 Windows 不可用，因此从 GitHub 获取临时源码快照。已阅读 AGENTS.md、index.css、Sidebar、TopHeader、ListView、SettingsModal 及其样式，以及 ui 目录内 Button、Modal、Select、SegmentedControl、DropdownMenu、Tooltip、Toast 的相关实现。参考工作树未修改。

原有首页播放器/波形、频谱、时钟三栏、右侧节目属性，以及灯光工具栏、素材区、右侧 Cue 和下方时间线结构保留。没有复制分镜业务、修改工程 schema 或改变设备权限。

深色表面沿用 `#08080a / #0e0e11 / #15151a / #1d1d23 / #25252d`，浅色沿用 `#f2f2f5 / #ffffff / #f1f1f4 / #ffffff / #e6e6ea`。强调色分别为 `#0a84ff / #007aff`。字体使用参考系统字体链，在 Windows 实际由系统可用字体显示。圆角与间距采用参考刻度，不新增渐变或大阴影。

## 有意保留的适配

- 小字号白色主按钮文字需要更高对比度，增加语义填充色 `#0066cc`；参考强调色 token 保持原值。原有可读辅助文字映射到 text-2，避免直接使用参考的低对比装饰文本色。
- Windows 顶栏保留现有 54px 和窗口按钮行为。毛玻璃由 Electron CSS backdrop-filter 实现，不声称实现了 macOS 原生系统 Vibrancy。
- 保留现有原生 select、title 提示与 dialog 焦点逻辑，没有为复刻外观替换技术栈或新增一套 Radix 控件。
- focus、disabled、loading、invalid/error 统一；保留 reduced-motion，并增加 reduced-transparency 的实色退化。

## 用户反馈后的布局修正

- 设置右侧取消居中窄卡片，内容靠左展开，表单行高从 64px 收紧到 48px，去掉“工作环境”等重复页头信息。
- 编辑器预览/属性/时间线分隔条增加可见抓手；取消时间线 48% 高度上限和属性 700px 拖动/480px 保存上限。按容器剩余空间限制，仅保留避免面板完全消失的最低尺寸。支持指针拖动、方向键、尺寸持久化以及中断清理。
- 首页播放器保留三栏结构，播放、播放方式/淡入淡出、音量、时间码状态分别对齐；选中节目后仅保留一个 MTC 开关。同步调整容器高度，避免遮挡节目单工具栏。
- 后续验证：类型检查、Lint 和构建通过；自由拖拽与返回页面后恢复尺寸、连续输入和弹窗测试通过；重新运行主题/窗口尺寸/14 个设置分类/真实波形内容验证通过。

### 节目单交互与重点层级补充

MTC 全局入口调整：播放器底部的时间码状态和重复开关移至顶部可点击的 MTC 状态按钮；主控显示待发送/发送中/已关闭/直接 Cue，跟随显示接收状态。点击打开状态面板，提供接口、端口、原有发送详情、输出开关及音频与 MIDI 设置跳转。编辑器的时间线状态仍保留。类型检查、Lint、构建、顶部开关和设置跳转、深浅主题与不同窗口尺寸验证通过（test-results-topbar-mtc）；未进行真实 MIDI 收发验收，未打包。

后续按用户要求移除固定多选操作栏：框选后右键选中卡片或空白区域，菜单显示“删除所选 N 个节目”；右键未选中卡片回到单节目菜单。保留 Delete、Ctrl+A、Escape 和删除确认/撤销。构建与覆盖右键批量删除、取消、撤销、拖入文件的 Electron 测试通过（test-results-program-context-menu）。

- 正计时与倒计时独立使用 emphasis 色和 700 字重，不再随辅助文字变暗；选中节目与批量选择使用明显蓝底、蓝边和亮色名称。
- 卡片调整为约 164×104px、8px 间隔、8px 内边距。普通界面文字禁用原生拖选，输入框和可编辑内容保持文本选择。节目卡片不再被原生拖走；归属播放列表仍可在属性修改。
- 节目列表空白处拖动框选、Ctrl 点击增减、Ctrl+A 选择当前可见节目、Escape 清空，按钮或 Delete 批量删除。删除沿用确认交互，整个批次作为一个 LinkCommand，可一次撤销；不删除源媒体文件。筛选和列表切换清空批量选择。
- 外部音视频文件可以拖到节目列表（含已有卡片），按文件顺序新建节目。与“添加节目”共用导入流程；未保存工程先请求保存路径，取消即不导入。视频保留画面素材、片段及提取原声。失败显示已完成数量并停止后续导入，不切换工程会话；运行锁定时拒绝拖入。
- Electron 实测 WAV 和含音轨 MP4 拖入、保存后数据检查、批量删除/取消/撤销、Ctrl 多选/全选、文本选择样式及输入回归通过。深浅主题、3 种窗口尺寸的既有界面检查通过。其他视频编码、没有音轨的视频及第三方应用的非文件拖拽未验收。未打包。
