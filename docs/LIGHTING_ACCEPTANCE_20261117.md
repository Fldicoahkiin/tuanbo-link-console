## 已修复的原因

1. 同一 TC Slot 的多条时间线开启 AutoStart，外部 MTC 越过旧歌范围后，MA2 仍会响应并通过 StatusCall 恢复旧歌最后一步。增加 MA2 原生辅助选曲 Timecode/Sequence，由 MIDI 时间码选择当前区间。网络只负责编辑、准备和同步。
2. 当前歌曲的 Cue 带着原生 Time 触发，其中一步会在上一 Cue 后 0.5 秒自动前进，抢先于时间线。准备时将歌曲所用序列的自动触发改为 Go，保留灯具数据、Fade、Delay 和命令，完整备份并逐 Cue 指纹确认。
3. 第零帧 Event 的 XML 没有 time 属性，原范围扫描把它漏掉；现在按第零帧计入。
4. 明确连接准备选曲和后台同步可能同时进入。读取期间后台等待，主进程准备请求串行，错误仍返回各自调用者。
