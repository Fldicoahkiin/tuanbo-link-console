# 团播联动台商业化设计

日期：2026-09-21。状态：可评审方案，尚未接入真实支付、签发授权或限制现有用户。

已确认：买断与订阅同时提供；首批客户为多直播间团播公司；一台主机销售一份独立授权，不附赠备机。本文价格、服务额度和授权细则为建议，不能直接作为已生效价目表或合同。

## 1. 产品定位和销售单位

销售“节目、音乐、画面与灯光的一体化现场编排及联动”，主要价值是降低多直播间培训、重复操作和现场排错成本。不能宣传替代 OBS、灯光控台或直播伴侣，也不能承诺自动开播、涨粉或收益。

以主机为销售单位：一台主机需要一份独立授权，不采用并发浮动主机授权。主播人数、操作员账号、节目数、素材数、Cue 数均不计费。操作员可以交班，不额外购买人员账号。

一份授权只绑定一台主机，第二台和备机均需另购。公司套装只是多份单机授权的采购折扣，不允许多台电脑共用一份授权。免费编排电脑不得执行正式输出，换机需办理原授权迁移。

产品不拆出残缺的基础版和复杂的灯光插件收费包。所有付费主机授权具有相同且已验收的核心能力；企业采购差异体现在主机授权数量、集中管理和服务，不体现在故意限制节目数量。

## 3. 免费编排、试用和到期行为

免费编排模式允许打开、编辑、保存、备份自己的工程，以及不向外部正式设备发送动作的本地预览。禁用正式 OBS 控制、对外 MIDI/MSC/MTC 输出、控台写入及联动启动；设置、诊断和查看日志仍开放。必须沿实际输出边界统一执行，不能只禁用播放按钮；自动连接也不能绕过授权触发写入。

公司试用默认 14 天、1 个单机授权，不要求银行卡，首次申请试用才开始计时。需多直播间联调可由运营增加到 3 台，延长一次 7 天并记录原因。试用期内功能与已发布付费版一致，不在节目中插广告、静音或水印。

试用/订阅到期在开始新的正式运行会话之前检查。已开始的现场会话不因到期、授权服务器断线或后台吊销而突然停止音乐、切场景、断开 MIDI。会话不等于单首歌；内部歌曲切换及 P1 自动选歌仍属于当前会话。结束会话、退出应用后重新运行则重新检查。

提前 14/7/3/1 天在设置与启动页温和提示；正式运行中不得弹模态付费窗口。订阅提供一次固定 7 天续费宽限，截止时间由签名授权给出，不能每次重装重新获得。宽限后保留免费编排和全部数据读取保存。试用没有额外自动宽限。

买断只区分“使用资格”和“更新资格”，界面不能用“授权已过期”描述升级服务到期。安装新版前明确是否需要购买升级，并保留可下载的最后合格版本；兼容性变化必须备份，不能强制降级打开已升级工程。

## 4. 设备绑定、换机和离线

- 公司拥有组织账号；管理员购买和分配主机授权，操作员只使用分配好的设备，不接触账单和支付凭证。
- 激活通过浏览器登录或短时设备码完成；激活码只作为一次性兑换凭据，不能把永久许可证密码长期公开在客户端。
- 设备安装时生成密钥对；私钥通过 Windows 安全存储保护。授权绑定设备公钥，适度参考硬件变化做风险提示；避免单独绑定 MAC、硬盘序列号而导致换网卡就失效。
- 正常换机先释放旧设备再激活新设备。丢失/损坏设备可申请强制释放，建议每席每 30 天自助 2 次，超额人工处理；同机重新安装也有恢复入口，不能只能重新买。
- 不提供主备机共用资格或自动接管。同一授权迁移到新主机前需处理旧主机资格；离线旧主机无法即时撤销的限制必须向客户说明。
- 买断设备授权支持长期离线；订阅授权离线有效期不超过已付费服务期加固定宽限，联网时刷新。首次离线激活可导出请求文件，由另一台联网电脑登录公司门户领取签名授权文件。
- 客户端通过签名校验许可证，使用服务端签名时间锚点、本机已知时间高水位和单调运行时间检测明显回拨。无法保证被管理员完全控制的电脑绝不绕过，应将收益投入到稳定性与服务，而不是承诺“无法破解”。
- 永久离线许可无法即时撤销，设备迁移、退款后的旧设备离线重复使用也无法完全杜绝。保留撤销名单供联网同步；商业上接受有限风险，严重滥用按合同处理。
- 时钟异常、证书问题或权限变化发生在运行中仅提示并记录；在下一次会话前处理。停止/断开/保存/恢复操作永不因授权而被禁止。

## 5. 购买、支付、退款和售后

完整流程：选择公司及主机授权 → 展示方案、金额、服务日期、发票及条款 → 服务端创建订单 → 官方扫码收银台 → 支付渠道验签/查单确认 → 幂等发放权益 → 分配并激活设备 → 下载对应版本及配置指南。

首期建议接微信 Native 扫码，支付宝作为下一渠道；也支持公司合同对公付款，人工核款后通过有审计的管理后台发授权。禁止凭客户付款截图自动发货，禁止把收款密钥放 Electron 中。

订单金额由服务端商品版本、主机授权数和优惠计算，客户端不可上传最终应付价格。支付回调必须验签、解密、核对商户、订单、金额和币种；同一支付流水只产生一次权益变更。主动查单与回调共用同一事务。支付成功但发货失败显示“已支付，授权处理中”，服务端可重放任务，不让客户再次付款。超时关闭与迟到支付按查单最终事实处理。

退款规则作为待法务核定的商业承诺：首次购买 7 天内可申请兼容性退款；先支持复现，无法解决可退，不用“已激活概不退款”覆盖所有情形。重复购买、支付成功未交付由客服核对处理。部分退授权根据订单实付和主机授权明细计算，不能退完套装再保留所有权益。买断退款需告知注销授权；离线撤销限制见上一节。

退款状态与渠道退款单绑定；退款确认前不当作已退款，退款确认后更新权益、发票处理和审计。撤销权限不打断已运行会话。折扣、退款、续费、升级都保留原订单价格快照。

基础支持建议工作日 10:00—19:00，1 个工作日内首次响应，属于响应目标，不是解决时限；首期不卖无人值守的 24 小时 SLA。

可选服务建议价：远程部署 999 元/公司（最多 3 台、一次预约、最多 2 小时）；培训 1,499 元/2 小时；现场交付按工时、差旅和范围单独报价。软件缺陷排查不能强制转收费培训。备份、预检、日志导出不得成为高级付费功能。

## 6. 软件与公司门户的界面

遵循现有紧凑桌面设计，不在编辑器、节目单、播放区加入广告条或永久购买横幅。

设置新增“账户与授权”：

| 区域 | 展示内容与动作 |
|---|---|
| 当前资格 | 公司、方案、主机授权名、绑定主机；买断显示永久使用，订阅显示服务截止 |
| 升级服务 | 独立展示更新时间范围和可用版本，不能混作使用到期 |
| 设备 | 设备名、最近验证、离线可用说明；激活、释放、换机申请、导入离线授权 |
| 订单与帮助 | 在公司门户查看账单、续费、退款申请；诊断信息可复制且不含秘密 |

首次启动先选择“开始试用 / 激活已有授权 / 免费编排”，能立即继续使用。公司已购买时输入设备码即可分配，不要求每个操作员扫码付款。

公司门户包括总览、主机授权与设备、成员权限、订单发票、续费升级、工单。角色：所有者可管理所有权限，管理员分配设备，财务管理账单，操作员仅使用设备。转移所有权必须重新认证且留审计。

运营后台包括客户、订单、支付对账、授权/主机授权、设备释放、退款、试用延长、版本发布、审计。手工发放赠送/测试许可必须注明有效期和原因；运营人员不能直接导出签名私钥。

## 7. 技术设计与仓库落点

保留 Electron + TypeScript + Zod。新增小型 TypeScript 授权/订单 API 和关系数据库即可，不首期拆微服务。客户端只持签名公钥，服务端签名私钥由专门密钥服务或受控签名进程保管，不进仓库、前端包或日志。

建议实体：organizations、memberships、products、price_versions、orders、order_lines、payments、refunds、entitlements、seats、devices、activations、license_issues、audit_events。订单和支付流水具唯一约束；所有操作带 requestId、actor、organizationId；跨公司访问强制服务端校验。

授权载荷：schemaVersion、licenseId、organizationId、seatId、devicePublicKeyHash、licenseType、featureSet、issuedAt、useUntil（买断为空）、graceUntil、updatesUntil、keyId。以标准、经过验证的签名格式签发，固定允许算法和编码，禁止自创加密或客户端自行生成授权。

客户端边界：

1. packages/schema 定义授权状态与 IPC DTO，不向 LinkProject 加授权字段。
2. main/link 的 LicenseService 校验签名、设备和时间资格，保存受保护的本机状态；renderer 只显示结果。
3. runtime 的正式会话入口和主进程外部输出边界检查许可，使用进程内会话句柄承接运行中资格。禁止只靠 renderer 按钮隐藏；播放、P1 布防、自动启动、MIDI 输出、控台写入都要覆盖。
4. 将正式设备输出与本地编排/预览分开授权；原 Command、工程 schema、预检及错误处理保持不变。
5. 会话检查仅发生在准备/启动阶段，云端授权服务不得成为 Cue、音频时钟或 MTC 实时路径中的依赖。
6. 商业更新接口只返回符合 updatesUntil 的版本；提供公开签名下载或短效下载地址，移除客户 GitHub Token 配置。签名验证失败阻止安装，不替换正在运行的版本。

关键 API：创建/查询订单、支付回调、领取权益、设备激活/释放、下载离线授权、刷新授权、查询合格版本、申请退款。支付回调幂等、激活并发控制、组织权限隔离和签名密钥轮换必须有测试。

后台故障时，已有有效离线授权继续运行；新付款保留订单可查、等待补发；不临时默认为未授权，也不通过隐藏异常伪造成功。

## 8. 正式销售前的门槛

初始源码核查未发现商业化模块；现已新增离线签发与本机验签基础，真实支付、权限拦截及企业管理仍未完成；UpdateCenter 仍有客户 GitHub Token 配置；THIRD_PARTY_NOTICES 记录了 GPL FFmpeg 与 IBT/Marsyas。既有文档还明确实体 MA2 未完整验收。旧记录不是本次重新验收结果。

必须完成：

- 实体 MA2 的连接/登录、Cue 读写回读、MTC 时间对齐、断线和恢复验收；OBS、内部音频与 P1 核心工作流长时运行。此前“点连接无反应”不能仅靠模拟测试就算现场修好。
- 全新 Windows 安装、签名发布、更新/回滚、普通权限、不同 DPI、弱网/断网、单机绑定、设备迁移；正式输出期间不弹购买窗口、不自动停止。
- 授权试用到期、订阅宽限、买断升级到期、撤销、回拨、克隆、离线签名篡改；可随时保存/导出用户数据。
- 支付金额篡改、重复/乱序回调、付款后断网、退款重复处理、并发抢占主机授权、组织越权、服务端灾难恢复。
- 商户主体、支付签约、发票、最终用户协议、隐私说明、退款政策及实际部署地区要求落实，最终条款由相应专业人员核定。
- 分发物许可证审计：FFmpeg 对应源码/构建配置/许可材料、IBT 源码与构建、OBS 原生插件及其链接方式逐项核查。GPL 允许收费，但收费不免除许可证义务；不能因为外部进程通信就自行宣称闭源方案已合规。

试点合同明确支持的硬件和软件版本，不把未验收功能当正式卖点。上线首期建议 3—5 家公司，每家先 1 个直播间跑通再扩到多席。

## 10. 收入测算与持续决策

用 3 台年付 5,999 元计算：10 家年合同额 59,990 元，30 家 179,970 元，100 家 599,900 元，分别对应 30/90/300 个单机授权。这是情景计算，不是销量预测，也不是净利润；服务费不计入稳定续费收入，买断收入不计入 ARR。

每客户贡献 = 实收收入 − 退款 − 支付渠道费用 − 税费 − 云服务分摊 − 获客/渠道佣金 − 实际支持工时成本。买断还需预留后续维护成本，不能把首笔现金全部视为利润。

首批记录：试用开始→首次成功联动→第二直播间上线→付费转化；另统计每席支持工时、激活成功率、故障会话、退款原因、续费和增购主机。指标只上传去标识的产品事件，工程、音视频、节目名和控台内容不默认上传。诊断附件由客户主动选择。

首轮 10 家价格访谈＋3—5 家真实付费试点后调价：若支持成本过高，先修复部署和诊断，不简单压低售价；若客户只愿买单机，重新验证多直播间定位；不要在无数据时规划大量渠道代理。

待经营者确定：正式产品名称及商标、销售/收款主体、报价和税务口径、域名/服务器、客服资源及联系方式、首批试点名单。已确定的买断＋订阅和公司客群无需再次询问。
