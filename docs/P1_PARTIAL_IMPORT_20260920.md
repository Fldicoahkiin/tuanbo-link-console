# 0.4.7 P1 部分导入与联动台主控

用户明确要求由联动台播放音乐、通过 MIDI 带动灯光，不依赖 P1 进程；允许逐条跳过失败音频。

- P1 原始 XML 结构解析与单条素材校验分离。裁剪无效、路径缺失、解码失败、时间码无效等逐条记录，其他歌曲继续。全部失败才返回整体错误。损坏 XML 仍拒绝。
- 成功歌曲保留原 MidiStartTime，内部音乐播放位置加该偏移驱动 MTC，不重新分配现场时间码。
- “仅 MIDI”页面导入完成后通过 LinkCommand 进入内部主控，同时关闭旧 P1 自动跟随开关；P1 跟随入口仍保留。
- 跳过清单保存到工程，在页面持续显示列表、歌曲及失败原因。重复读取时，既有失败歌曲暂禁用，不误删用户旧内容。
- 写回 P1 时保留跳过条目的 XML，并按原位置插回；重新计算所有条目的路径出现序号，防止同路径多次出现导致绑定错位。原 P1 文件不覆盖。
- 包含 0.4.6 的分数毫秒与 MP4 短音轨修复。

验证：824 项单测通过、35 项条件跳过；类型、Lint、构建与 NSIS 产物检查通过。后端部分导入测试覆盖坏裁剪、缺失素材、重复路径绑定、原始时间码、工程保存重开及跳过条目导出保留。3 项针对性 Electron 测试通过，最终打包程序再次通过部分 P1 导入/写回和 44 秒 MP4 流程。首次安装、同版覆盖、隔离启动、正常关闭、卸载通过，进程和注册项无残留。

限制：缺少用户报错原素材，未确定该首音频的时长异常原因；该条目现在可明确跳过，不阻断其余歌曲。没有现场实体控台，不能将 MTC 发包与内部播放测试等同于真实灯光效果验收。控台需接收电脑 MIDI 输出，并保留与歌曲原时间码对应的灯光时间线及帧率。
