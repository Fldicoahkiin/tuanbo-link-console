## 现场复核顺序

1. 使用现场真实网卡自动连接，核对 Show 名称和版本；按钮第 4/5 页、推杆第 100 页与照片逐格比对，包含空格、跨格、名称及真实页号。
2. 在专用测试对象上，分别从软件和控台改 Cue/序列名称，观察对端原样回读；同时改同一个字段应保留两边内容并提示冲突。
3. 在新测试歌曲添加 40 个点位，目标按钮页为 1000；确认分配到空格、同一 Sequence 内 40 步，编辑器能定位具体地址。控台新增步骤应出现在素材中，不能猜测音乐时间。
4. 用已有普通控台用户连接实时推杆，双向改变值，核对功能和单位；检查 Go、Off、按住/松开、失焦及切页。断开连接后旧操作不得在重连时补发。
5. 对现场同一首音频播放、切页并执行音乐识别，检查单个后台任务正常结束；对比两个已知 Cue 的“单独运行 / 跟随上一个”实体出灯行为。

测试应使用明确的专用对象；空 Cue 删除仍须读取并核对清单，不因验收批量删除现有控台内容。
