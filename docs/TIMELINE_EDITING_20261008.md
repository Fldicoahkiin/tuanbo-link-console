# 时间线与灯光编辑交互（2026-10-08）

## 本轮行为

- 普通编辑器：音频片段可移动、左右裁剪、数字编辑、分割、删除和撤销；单次拖动形成一次修改。边界校验限制源素材、邻接片段及最短时长，原始音源不删除。
- 灯光工作台：音频仅作参考波形，点击/拖动定位，右键打点；无音频编辑菜单、裁剪手柄和选中白框。
- 时间显示按实际值省略零小时、零分钟，保留帧精度；外部 MTC 状态仍显示完整时间码。
- 点击波形或标尺取消 Cue 选中；编辑 Cue 时的素材分类切换、素材添加及编辑区操作保留当前目标。
- 左侧灯光子菜单改为控台素材、面光、轮廓、效果，取消重复的 Cue 编辑器和素材库入口。读取与手动同步保留在设置 → MA2 控台；导入导出、播放选项放在更多。
- Cue 编辑面板显示名称和素材列表；保存固定在面板顶部。每个素材的序列、Cue 编号、延迟及执行器折叠显示，支持移除、埋步和存入素材库。
- 编辑已有 Cue 时，控台单步与分类素材的加号或拖入编辑面板，添加到同一 Cue 的草稿。保存更新原点位，保留原事件 ID 和时间；撤销整体恢复。拖入时间线仍是明确的新建点位操作。
- 控台素材标题栏的五个冗余操作入口移除，保留全局停止试听。
