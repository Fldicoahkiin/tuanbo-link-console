# 0.4.10 连接结果修复

截图中的“仍有 N 个阻断项”来自一键连接检查，不是节目预检的完整报告。

## 原因与修复

- 原先详细原因只在 P1 跟随模式的维护区域显示。内部主控模式无法看到列表。现在每次连接完成后弹出独立结果窗口，保留每项具体原因、影响说明和设置入口。
- 原先 MIDI 监视适配器的端口档案解析函数始终返回 null，但一键连接又使用该对象打开输出端口。现在实时读取机器集成配置，避免“已识别并保存端口、打开时仍说档案不存在”。
- 连接结果不再一概称为阻断项；原有节目播放、布防检查保留。
- 未检测到可执行文件不再显示“已安装”。未保存 OBS 密码不再被描述为已经检测到 OBS 开启认证。
- 跳转入口：OBS 连接 → OBS 设置；程序位置 → 高级与诊断；MIDI → 音频与 MIDI；MA2 → 控台设置；虚拟 MIDI → 虚拟 MIDI 设置。

## 验证范围

完整 Windows 发布检查与 Electron 回归。连接结果测试在内部主控模式从顶部一键连接进入，验证明细弹窗、OBS 设置跳转、不出现 MIDI 档案不存在误报，并继续验证 Cue 发包与关闭发包开关。

截图只有问题数量，无法据此还原现场的三个具体错误；修复版需要在现场重新执行一键连接查看实际结果。测试未代替现场设备验证。
