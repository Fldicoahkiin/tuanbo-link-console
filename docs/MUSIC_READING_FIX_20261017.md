# 0.4.51 音乐识别与读取进度修复

## 行为

- 音乐后台任务不再因切换页面或开始播放而取消、暂停或重新排队。同一任务完成后，返回对应歌曲并停止播放时，通过工程命令写入分段。
- 自动分段使用节拍与音频特征，不再运行人声分离，也不标记主歌、副歌。保留三组节拍模型。
- BPM 逐段计算；节拍不规则时显示局部中位估计，不再显示“待核对”。没有足够可测节拍时明确显示“无可测 BPM”，不编造速度。
- 素材、属性分类与音乐识别进度统一在左侧菜单下方。显示真实完成数与总数；音乐显示已完成阶段数；未知总数时静止等待，不使用循环动画假装进度。
- 素材刷新与自动分类按钮移到左侧。“控台布局 / 新建 Cue”移到左侧“更多”。移除素材区右上 Layout 工具行、右下未回读状态行，错误仍在左侧显示。
- 新读取的控台素材目录可以替代较早的时间线缓存，不修改时间线绑定；较新的不同会话仍拒绝混用。
- MA2 网络传输出错后只释放本次成功取得的请求，不重发写入，不清理其他客户端请求。
