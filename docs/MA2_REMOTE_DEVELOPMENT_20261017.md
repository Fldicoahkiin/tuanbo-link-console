# MA2 现场开发连接与名称修复（2026-10-17）

## 现场问题与修复

现场单步素材卡片只显示 `Cue 1.000`，悬浮提示却有序列名（例如 `xws man 170`）和“未命名”Cue。平铺素材池优先显示读取到的控台 Cue 原名；Cue 没有名称时显示所属控台序列原名；两者都没有时才显示编号。进入多步序列后，每一步只显示自己的 Cue 原名；无名时显示实际编号，例如 `Cue 1`、`Cue 2`、`Cue 2.5`，不重复使用所属序列名称。控台池不使用历史本地别名替换原名；用户明确右键改名时立即显示待同步的新名，回读确认后更新控台名称缓存。拖入编排、加入 Cue、右键菜单沿用所在视图的显示名称。

设置页此前独立覆盖全局侧栏宽度、背景、字体和按钮间距，进入设置时菜单会缩窄且行高变化。已移除这些覆盖，设置内容样式只作用于右侧工作区；左侧主菜单复用其他工作区的尺寸和主题样式。

多步序列卡片右侧及进入序列后的顶部显示“共 X 步”，按读取到的 Cue 条目数量统计，包含小数编号 Cue，不用最后一个 Cue 编号代替数量。19:05 ToDesk 现场已看到 `love shot 346` 共 16 步、序列 388 共 37 步；真实安装产物验证了卡片和顶部步数显示，TypeScript 与 ESLint 通过。

编辑 Cue 的“包含素材”原先只从分类模板或点位标签重建名称；空点位标签保存后，拖入的 `bj 294` 退回 `Cue 1.000`。现在按序列及实际 Cue 编号从工程中保存的控台目录解析原名，未命名 Cue 使用所属序列名；副行保留所属序列及 Cue 编号。组合点位名称独立，不覆盖素材名称。目录更新和手动修改 Cue 引用后重新解析名称；无需新增工程字段或重启主进程。19:11 ToDesk 现场确认已有素材立即恢复显示 `bj 294`，副行仍为“序列 294 · Cue 1”。

旧的批量缓存关联在准备条目后才整体确认配对，一条确认失败会回滚所有可用条目，并阻断接下来的全控台素材读取。现在先在逐条检查阶段验证配对，失败原因随 Timecode 保存，其他有效条目继续关联。最终写入仍使用一个可撤销的 LinkCommand，并再次确认有效条目。

配对错误现在区分缺少歌曲依据、控台读取异常、不支持的帧率、无事件、无效时间格式，以及具体事件超出歌曲范围。未放宽原来的 30 FPS 和歌曲范围检查，也没有改写控台帧率或推测歌曲对应关系。

## 开发连接

2026-10-17 19:31，现场用户已修改的序列 1 / Cue 1.000 名称 `666`，通过独立名称同步写入 MA2 并回读确认。名称待同步项消失；当前歌曲的两个未关联点位仍保留，未自动创建对象或写入歌曲时间线。右键改名现在自动启用名称同步，不依赖歌曲的实时同步开关；播放期间暂存，停止后检查目标、存档、写入和回读，错误后保持阻断，不自动重试。

空原名的首次改名此前在回读后重建撤销历史时被非空字符串约束拒绝。工程改名记录现在允许历史恢复值为空，用户提交的新名称仍要求非空。旧桥不支持清除名称，撤销至未命名状态会明确提示到控台清除并重新读取，未发送清空指令；不会把无名改成伪造的默认标签。普通非空名称的撤销、重做仍自动写回。

序列显示名此前来自 `getobj.name`，其中包含控台追加的对象编号。新版主进程按页读取 `getobj.label` 的原始序列及 Cue 标签，并核对两次读取和分页一致性；保留标签本身的数字，不用截断字符串猜测名称。该修复需要更新测试版主进程后重新读取素材，单独界面热更新不能修复旧缓存。网络 Lua 桥保持与已部署版本逐字节一致，避免仅换行变化触发现场桥版本冲突。

这次采用既有 0.4.46 免激活测试版主进程和开发服务器界面组合。测试电脑无需安装 Codex、Node.js 或 pnpm。启动器只给自己启动的联动台进程设置 `ELECTRON_RENDERER_URL`，没有写入全局环境变量，也没有覆盖已安装文件。

直接使用局域网 HTTP 页面会缺失浏览器的安全上下文媒体接口。启动器因此在测试电脑的 `127.0.0.1:43189` 建立固定目的地转发，让界面从本地地址加载。转发只监听本机回环地址；开发服务器路径使用独立会话随机值。开发连接窗口随本次启动的联动台退出而关闭，不强制结束程序。

开发入口只热更新 renderer 及其引用的共享代码。主进程、preload、原生组件、Lua 桥仍使用已安装版本；涉及这些部分的修改需部署并重启后验证。远程开发不可替代最终安装包验收。

启动器从当前用户/整机、32/64 位安装记录和桌面/开始菜单快捷方式定位软件，手动选择时允许选择程序或快捷方式，并检查同目录存在 `resources/app.asar`，避免误选安装包。应先保存工程、正常退出联动台，再打开开发连接。原桌面快捷方式仍启动原离线界面。开发服务和两机网络需保持可用。

本次部署脚本、启动器、连接配置和隔离验证证据在忽略目录 `artifacts/ma2-remote-development/`，启动服务器脚本是 `artifacts/start-ma2-remote-renderer.mjs`。会话地址没有写入工程或此文档。
