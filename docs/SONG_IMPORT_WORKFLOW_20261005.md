# 歌曲导入与设备菜单（2026-10-05）

## 常用流程

1. 首页或节目单点击“导入歌曲 / P1”，也可打开设置 → 设备连接 → 歌曲导入。
2. P1 工程直接选择 `.hia`。导入歌曲、裁剪与原始时间码，使用联动台内部主控；无需先连接 MA2 或启动 P1。首次导入需选择联动工程保存位置。
3. 在音频与 MIDI 设置声音和时间码线路。已有控台时间线通过正确配置的时间码线路运行；是否实际出灯仍由现场验证。
4. 连接 MA2 后读取、配对控台编排，进入编辑器处理 Cue。

需要继续在 P1 中播放时，在歌曲导入页展开“继续使用 P1 播放：跟随与写回”；不再到程序维护寻找导入入口。常用导入和写回分开显示。

设备菜单按准备歌曲、声音画面灯光、辅助工具分组。歌曲金色、音频青色、画面蓝色、灯光紫色；颜色表示用途，不表示连接成功。标题 15px，短说明 13px，分组 13px，深浅主题均保留文字标签。

## 小红花：已实现与未实现

已确认产品为 https://yx.xddck.com/ 的小红花音效助手。歌曲来源页提供小红花入口，**只支持导入用户自己保存的原始音频文件**，复用本地音频导入、工程保存与内部播放流程。普通音频没有 P1 时间码，不会伪造原有歌曲与控台的关系。

**完整小红花支持未完成。** 官方 [无法导出音效](https://yx.xddck.com/question/wfdcyx.html) 表明其备份/分享包只可在小红花内部使用，不支持直接导出音乐到其他播放器；[自定义音效说明](https://yx.xddck.com/course/drzdyyx.html) 要求保留自有音乐文件。

尚未取得可验证的工程包格式、播放位置接口或时间码输出接口，因此不能确认导入内部音效、分类、剪辑设置，也不能实现可靠的外部播放跟随。快捷键只能触发操作，不能代替实际播放位置。界面明确列出未接入能力，无假连接状态、不绕过包格式或加密保护。

继续实施需要可检验的数据格式/接口或供应方支持。用户要求“导入和跟随都要”仍保留为未完成目标，不能将本地音频导入等同于两项已完成。

## 本机验证

`song-import-workflow.spec.ts` 在实际 Electron 构建中点击首页入口，读取构造 `.hia` 和真实 WAV 文件，验证非零 120 秒原始起点、1–2.5 秒裁剪、内部主控、歌曲名称及 `.tblink` 实际落盘。返回节目单再进入导入页，已导入状态仍从工程显示。

小红花入口测试使用自有 WAV，验证文件导入与工程保存，不把它记作小红花备份包或外部软件同步验收。深浅主题截图见 `artifacts/song-workflow-readable-20261005`。本轮未生成新安装包。
