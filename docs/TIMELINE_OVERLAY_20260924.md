# 2026-09-24 时间线、透明素材与独立音频修复

本轮为开发版修改，未重新打包，已交付的 0.4.26 安装器不包含以下修改。

## 行为

- 时间线由同一个视口负责横向与纵向滚动，刻度固定在上方；左侧轨道名称同步纵向位置，横向滚动条始终在底部。普通滚轮在多轨时上下滚动，Shift 横向滚动，Ctrl 缩放。灯光工作台保留原有滚轮定位行为。
- 上方媒体轨叠加到下方完整机位场景，使用独立的应用自有叠加场景嵌套来源；OBS 完成透明合成，不修改用户机位内部来源、滤镜与变换。特效结束后恢复底层机位。相同素材的同时重复叠加仍会明确拒绝，因为一个素材对应一个 OBS 解码来源，不能伪装成独立播放位置。
- 精确定位缓存采用 FFV1、BGRA、全关键帧，保留透明通道；使用新的缓存文件名，不复用旧的不透明缓存。编码限制为两线程。
- 暂停内部播放时，音频修改先停止原会话再执行 Command。音轨与片段可独立编辑/删除/撤销，点击波形后 Delete 能收到键盘焦点；音频剪辑属性置于节拍检测之前。
- 在线预览不再在每次播放时钟更新时计算离线场景计划；实时画布隔离父组件的时钟重渲染，保持单个帧请求及背压。
- 包含中文场景名的 OBS 英文缺失来源错误改为中文。开发版原生桥路径按编译入口解析，不依赖 Electron 的启动参数改变 appPath。

## 验证证据

- Windows 11，OBS 32.2.2，用户提供的 `扑克牌特效.mov`：1080×1920，60fps，QTRLE/ARGB，约 2.2 秒。在独立便携 OBS 和测试工程验证，不修改现场 OBS 的场景。
- 原素材透明叠加：53 个不同视频帧，约 30.7fps；启动与建立叠加约 45ms，透出下层测试蓝色画面。画面及读回结果保存在 `artifacts/overlay-timeline-20260924/`。
- 定位缓存生成约 2.08 秒。原始视频与缓存全部解码为 BGRA 后的 MD5 同为 `68b40f43f61e7424eb3dd9f700b9d56c`，包含 alpha；原生暂停定位到 1.2 秒后画面保留透明，状态为暂停。
- 完整 Electron 编辑器连接真实隔离 OBS：640×360 和 1080×1920 两种画布均完成播放、特效开始、特效结束和停止。竖屏测试 4.002 秒绘制 120 帧，约 30fps；50ms 界面探针最大间隔 59.1ms，没有场景缺失或 MTC 跳变日志。
- 竖屏测试进程 CPU 采样和工作集原始值见 `portrait-preview-metrics.json`。这些是四秒短测数据；GPU 进程的 CPU 值不是硬件 GPU 利用率，进程工作集也不能直接视作去重后的物理内存。未据此宣称长期资源验收完成。
- Electron 时间线测试在 1200×800、1920×1080 下验证 14 条视觉轨道的底部可达、左右对齐、固定刻度与实际滚轮。音频测试验证保存重开、修改落点、Delete 删除且保留视频、撤销恢复。
- 全量单测 916 通过、40 跳过；类型检查、Lint、开发构建通过。日志为根目录 `overlay-*.log`。P1/内部主控灯光工作台回归覆盖效果绑定、拖放打点、保存，不代表断开的实体控台验收。

## 限制

开发版完整重启后，原工程自动恢复；通过原生窗口实际滚动确认底部第三条视觉轨可达、刻度固定且轨道名称对齐。OBS 控制及真实预览就绪。启动时一次系统 MIDI 探测超时，手动刷新后检测通过并识别 5 个输出端口；这次恢复不代表启动超时原因已消除。实体控台仍断开。

本次未验证所有显卡、OBS 版本或其他 Windows 版本，也未进行数小时演出或 GPU 硬件计数器测试。实时画面测得约 30fps，对应测试 OBS 的 30fps 输出，不承诺素材 60fps 即可在任何机器上达到 60fps。现场原有工程仍需按实际机位与时间线播放验收。
