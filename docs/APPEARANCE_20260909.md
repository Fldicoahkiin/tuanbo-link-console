# 0.3.2 · 首页层级与黑白外观

首页分为工程与连接、播放主控、节目单与编辑属性三个区域。播放区使用一块连续的浅色/深色背景，突出当前歌曲与播放按钮；节目单标题加大，选中行使用蓝色反馈；右侧编辑区保持辅助层级。右上计时区没有额外标题。

左侧底部“外观”可选浅色·白、深色·黑、跟随系统。选择保存于本机，重新启动后保留；跟随系统通过系统配色变化事件实时生效。白色皮肤覆盖侧栏、首页、编辑器、原生下拉菜单与设置表单，深色提高正文与背景对比。素材本身颜色与 OBS 输出不会被皮肤改变，画布背景保持黑色。

外观切换不修改工程，不重建播放控制器。真实播放中切换浅色保持播放，暂停时切回深色仍暂停，继续与停止成功，停止后编辑恢复。renderer 无错误。

验证：287 项单元测试、18 项桌面流程测试通过，其中新增黑白切换、持久化、显式外观不跟随系统、系统变化实时跟随与文字颜色检查。最小窗口关键按钮无遮挡。安装、覆盖安装、正常关闭及卸载记录见检查记录。

用户素材仍保留原文件；本次外观改动不改变 MIDI 时间码、音频时钟、OBS 执行或视频编码。真实演出素材、实体灯具和平台直播仍需现场验收。
