# MA2 灯光后续开发与验收

日期：2026-09-15。用户要求完成剩余开发。本轮已新增并验证以下能力，**整个需求仍未全部完成**：播放中热写、MIDI 稳定播放及现场特殊格式仍有未解决项。

2026-09-17 MIDI 后续排查见 [Windows MIDI / MTC 稳定性记录](MA2_MTC_STABILITY_20260917.md)：已修复连接失效与媒体回跳防护。用户授权单次 MidiSrv 维护后，同一 loopMIDI 路径恢复并通过十分钟真实媒体回环（最大绝对误差 12.46ms，无字节不一致或 QF 失序）；维护前零接收、字节异常及时序超限证据保留。服务内部触发机制和实体控台仍未完整验收，不将整个需求更新为完成。

## 已完成

- P1 原始歌曲起始时间码转换：保留秒数字符串及明确的时分秒格式，将起点记录在灯光绑定和内部播放器配置中，不重新分配现场时间码。
- MA2 30 FPS 原生时间单位及非零整单位偏移往返：编辑器显示相对歌曲时间，保存原始 XML；写回逆向转换，帧对齐以原始时间码网格计算。多绑定起点不同、早于歌曲起点的事件或超出范围时明确阻断。
- 音乐试听和内部主控均使用绑定起点输出 MTC；直接触发模式不同时输出 MTC，避免重复执行。
- 设置中“一键读取当前音频与灯光”，也可通过导入菜单“选择 .hia 并读取音频与灯光”。音频使用现有真实 P1 导入服务；灯光根据完整时间区间与唯一名称配对。零起点不能仅凭只有一首歌自动匹配。不能唯一配对的对象保留待核对提示，不把它们计为已导入。已绑定对象不重复创建，不覆盖本地编辑。
- 常驻自动双向同步：显式启用后，停止播放时检查已绑定 Timecode；本地编辑静止 1 秒后触发检查，另有 5 秒周期检查控台变化。实际完成速度取决于 Show 规模和通信，非毫秒级热更新。
- 自动同步使用三方比较、原生快照、写前检查、备份与回读。冲突、对应不明确、换 Show/插件会话、通信失败均锁住会话，不自动重试。换工程结束会话。关闭设置页仍运行；重新启动软件需重新扫描并启用。
- 同步写入时阻止内部播放及编辑器试听启动。试听/正式播放期间自动同步等待。回读期间本地变化不会被覆盖。

## 使用步骤

本轮验收安装包：`acceptance-ma2-completion-build/Tuanbo-Link-Console-0.4.4-x64.exe`。
SHA-256：`A2505ED79555592A486AEBA7195828CAC15D14D3276F022EE92B6158FA4920C3`。未发布到更新服务，未在最终电脑安装。

1. 使用包含本轮修改的程序，设置 → 设备连接 → MA2 控台，连接正确的本机数据目录或实体控台。
2. MA2 导入并 Reload 上轮提供的新版 Lua 桥，然后运行；目录扫描需要 LIST 协议。
3. 点击“一键读取当前音频与灯光”，或选择 `.hia` 文件。检查“已导入”和“需核对”的分别计数。
4. 对待核对对象选择对应歌曲，点击“导入已配对灯光”。一条 Timecode 跨多首歌暂不能自动拆分。
5. 扫描后启用“编辑后自动双向同步”。出现冲突时关闭自动同步，在“查看与同步此时间线”内手动处理，再重新扫描启用。
6. 使用内部主控播放前确认 MIDI 时间码输出端口、控台 Timecode Slot 和播放准备状态；当前 MIDI 稳定性问题仍未验收通过。

## 尚未完成，不能作为正式演出替代版

1. **播放中对实体控台热写**：当前只完成停播自动同步。上面的事件接口试验没有找到可用写入口；需要进一步验证 MA2 支持的原生操作，并检查播放头连续、未来事件正确执行及过去事件不补发。没有移除整对象导入的停播保护。
2. **MIDI 稳定性**：此前真实 WinMM 发送失败/断流尚未解决；已询问是否允许重启 Windows MIDI 服务，尚未收到答复，未重启。软件发送代码和时间映射通过测试不等于实际灯光长时间播放通过。
3. **特殊现场数据**：非 30 FPS 显示格式、分数原生偏移、一条 Timecode 跨多歌曲仍明确拒绝。P1 非零 `cut_start` 原来会误用未裁剪音频，本轮增加明确阻断；没有实现裁剪音频的无损迁移。
4. **最终电脑及实体控台**：真实 P1 文件与音频只能在最终电脑访问。实体控台网络登录、真实歌曲配对及长时间播放尚待现场测试，本机文件桥验收不能替代。

MA 官方说明 Timecode Offset 会整体推迟事件：[Timecode Keyword](https://help.malighting.com/grandMA2/en/help/key_keyword_timecode.html)、[编辑 Timecode](https://help.malighting.com/grandMA2/en/help/key_timecode_editor.html)。XML 原始事件时间单位还核对了本机安装附带的 `timecode@sheet.xsl`，本轮实际启用范围仍为已验证的 30 FPS。
