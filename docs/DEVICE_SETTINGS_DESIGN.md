# 设备连接界面

2026-09-14 用户要求重做设备连接页面，解决文字不清楚、层级混乱和错位；随后明确否决大弹窗及灰色块层层嵌套的维护界面。

## 设计依据

参考 [Ableton Live 的设置分类](https://www.ableton.com/en/manual/first-steps/) 与 [Resolume 的 Preferences](https://www.resolume.com/support/preferences)：音频、MIDI、协议各自成组，先选择目标，再配置参数，高级选项逐步展开。采用专业桌面工具的稳定导航和表单组织，不照搬宣传网页样式。

已使用 `ui-ux-pro-max`、`ckm:ui-styling` 及 React 实现规范。项目指定的 frontend-design 和 TypeScript skill 未找到。检索器生成的营销页面建议不适合本产品，仅采用可读性、对比度、间距和交互规范。

## 当前实现

- 导航采用三列：左栏上方主菜单、下方设置分类；紧邻右侧独立一列显示子子菜单；最右侧显示设置内容。禁止把具体设置条目嵌套进左下分类。
- 所有设置分为设备连接、播放、画面与同步、外观与更新四组，共 13 个条目；两级设置导航沿用主菜单的文字、图标、按钮和选中样式。
- 设备列表：OBS Studio、MA2 控台、音频与 MIDI、虚拟 MIDI、高级与诊断。
- 右侧只显示当前设备；面板保持挂载，切换时保留尚未保存的字段。
- 连接状态用文字徽标；主连接操作、参数和高级维护分开。
- 音频线路和 MIDI 时间码独立成组；灯光动作与录制端口仍完整保留。
- 本机 MA2 数据目录直接显示在本机连接区域；插件和高级端口留在 MA2 面板内。
- loopMIDI 的程序状态、端口表、自启动开关和安装步骤分开呈现。
- 程序维护在页面内展开统一设置行，不使用全屏遮罩维护弹窗、不套叠灰色表单块。
- 表单正文 15px，说明 14px，输入控件 44px；Windows 中文系统字体。深浅主题使用独立语义颜色，键盘焦点有清晰轮廓。
