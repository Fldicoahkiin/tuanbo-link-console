# 0.4.54 界面检查

2026-10-20 后续执行器页面、按钮页 1000 落位、单灯光时间线、推杆实时通道和浮层修正见 [最新实施与验证记录](./MA2_EXECUTOR_PAGES_20261020.md)。本文件保留此前版本记录，新增功能的验收状态以最新记录为准。

目标：保持现有深色设计、菜单尺寸与紧凑素材密度；不让回读改变用户正在操作的页面。采用 better-ui 检查规范，沿用现有设计系统。

| 程度 | 位置 | 原表现 | 修改后 | 原因 |
| --- | --- | --- | --- | --- |
| 高 | Cue 编辑与 Layout | 名称回读会关闭正在浏览的页面 | 仅主动选中时间线点位时切换编辑面板 | 后台同步不能抢走当前视图 |
| 高 | 原位置视图 | 回读或拖动可导致整页重新缩放 | 固定当前视野，点击适应页面才重新计算 | 保持空间定位稳定 |
| 中 | 控台页面工具栏 | 低频工具挤占横向空间 | 单行紧凑按钮，目录与更多设置按需展开 | 给 Cue 留出空间 |
| 中 | 右侧区域 | 无操作时也占用素材区 | 仅选点或新建时显示编辑内容 | 优先展示素材与时间线 |
| 中 | 同步提示与名称输入 | 无改动核对也反复显示忙碌，输入可能被刷新 | 无改动时保持已同步，输入期间保留草稿 | 减少跳动与输入干扰 |
| 中 | 顶部编辑灯光 | 已接通仍可能显示未检查 | 显示实际连接，断开与恢复随状态更新 | 状态必须对应当前连接 |
| 低 | 属性分类与读取区 | 分类冗余，重复读取操作 | 移除属性分类入口，保留自定义类别与空 Cue 检查 | 遵循用户当前要求 |

本地已检查 1180×720、1920×1080、200% 缩放、原坐标比例和 40 Cue 编排；截图保存在 `artifacts/song-sync-ui/`。窄窗口可使用紧凑页；极窄顶栏状态区保留横向滚动，不宣称所有状态能在 200% 下同时展开。

本轮通过本地界面验收；真实控台、实体灯光与测试电脑尚未完成本轮验收。Layout 灯具符号及装饰并非完整复刻，完整同步边界见 `MA2_SONG_SYNC_20261019.md`。

结论：Approve（本地 UI）；实机验收待完成。
