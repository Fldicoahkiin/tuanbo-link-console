# 素材库界面调整

参考剪映桌面素材导入与浏览流程：https://www.capcut.com/resource/how-to-use-capcut 。本次吸收分类、缩略图和直接拖入时间线的交互方式，沿用联动台现有配色与 OBS 场景工作流。

- 本地素材和 OBS 场景分别浏览，OBS 未连接时明确显示离线。
- 编辑器侧栏宽度为 276px，本地素材默认两列缩略图，可用一个按钮切换列表。
- 常驻工具只保留导入、视图切换、更多、搜索和类型筛选。文件夹和排序从更多菜单进入，单项管理菜单只展示该项相关操作。
- 卡片操作仅在悬停、键盘聚焦或选中时显示。时长只展示一次，文件缺失明确标注。
- 竖屏缩略图保持原始比例；保留低功率开关和原有参考预览。
- 重命名时按 Enter 不再冒泡触发添加到时间线；菜单支持 Escape 关闭。

验证：Windows 原生构建、类型检查、修改文件 ESLint；Electron 用例覆盖 600 项搜索滚动、类型筛选、视图切换、菜单、来源切换和缩略图失败显示。截图位于 `acceptance-20260914-material-library-final/`。

全仓库 ESLint 另有非本次修改的 `workspace-actions.ts` 文件行数超限；未改动该文件。本次为界面与浏览管理调整，不代表 OBS 实机联调验收。
