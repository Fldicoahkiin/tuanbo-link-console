## 用户流程

1. 连接 MA2 网络，读取当前 Show 的素材目录。
2. 在歌曲时间线打点、命名或加入已有灯光素材。未编灯的空点位也可以创建到控台。
3. 灯光工作台「多步」右边选择「控台页面」，点击「新建 Cue」。在「本曲控台序列」设置按钮页码，默认为 1000。旧 Layout 工程保留原绑定。
4. 点击「创建到按钮第 1000 页并同步」。40 个时间线点位生成同一条 Sequence 的 40 个 Cue，分配到该页 101–190 中第一个空格，保留已有对象及跨格位置。
5. 点位编辑器显示按钮页码、格号、Sequence 与 Cue 地址，并可定位；点击原点位可重新打开编辑器。创建前检查页面是否已满，写入后核对实际分配。
6. 开启本曲同步后，软件修改 Cue 名称/素材会写入并回读；控台改名、改灯光内容、增加或删除步骤会回读。控台新增步骤显示到素材中，由用户拖入时间线指定时间。不会猜测其歌曲时间。
7. 软件删除已绑定点位后，须核对列表再删除控台 Cue。冲突和失败暂停同步，不自动重试。

## 页面与 UI

- 顶部「所有页面」枚举 Layout 1–9999 中的实际对象，选择后读取该页及引用序列的完整 Cue 名称。
- 默认使用原单步页的紧凑卡片。「控台原位置」按原始中心坐标及宽高比例显示，可缩放和拖动位置；拖动写回前检查页面版本，写后回读核对。
- 页面名称可以直接编辑并回读确认。旧页面不能覆盖控台的新位置。
- 页面实时回读是独立开关；进入多步序列仍可回读当前页的名称，后台歌曲回读不会抢走正在浏览的其他页面。
- 页面工具栏保持单行，低频设置收进更多菜单；右侧编辑器仅在主动选点或新建时打开。原位置视图后台更新不重新缩放，名称输入不被回读覆盖，无改动同步不反复切换状态文字。
- 顶部「编辑灯光」根据当前控台连接显示「已连接 / 未连接 / 连接中」，网络状态每秒回读；详细列表单独保留读写检查结果。网络已连接并不替代每次写入和回读验证。
- 隐藏旧属性自动分类入口与自动类别；保留用户自定义分类、排序、空 Cue 检查和删除清单。
- 单个点位可选择「单独运行」或「跟随上一个」。前者只 Off 本次软件已成功启动的目标，后者保留之前的组合；不发送 Off All。旧点位保持原有跟随行为。该选项支持网络直控和 MIDI，原生 Timecode 使用原控台编排。

## 同步边界

当前成果不能表述为“MA2 全部功能、全部对象、所有修改已经无条件双向同步”。

- 验证的 Layout 原生 XML 格式为 3.3.4 / 3.7.0；本次 onPC 实测为 3.7.0.5。其他版本须另行验证。
- Layout 中的 Sequence 按钮可展开、试听、拖入。其他池对象保留名称与位置但不调用；灯具符号当前仅报告数量，尚未完整复刻。图片、文本装饰、控台原生字体和灯具状态并非像素级复刻。
- 软件编辑歌曲点位和素材引用；没有在软件中实现 MA2 全套 Programmer、灯具参数编辑、宏、Patch、世界/过滤器等功能。
- 歌曲 Sequence 同步不自动生成歌曲 Timecode；控台上的步骤没有音频时间的，不能自行回填到时间线。原有 Timecode 工程保留原工作流，禁止直接转成歌曲 Sequence 覆盖。
- 静态组合包含已保存的显式属性；延迟、多 Part 和无法验证的结构会明确阻止，不静默压平。MA2 Tracking 的最终灯光效果仍需真实灯具验收。
- 自动核对按约 1.5 秒轮询，实际完成时间取决于网络和 Show 大小；不承诺零延迟。本地 40 Cue 未改动的一次完整核对约 2.8 秒。
- 播放期间按现有输出规则暂存修改，停止后同步；外部错误、版本变化、同项双方编辑会停下提示。
- 本曲仅可写入本工程在本机创建并记录所有权的 Sequence；页面追加也检查所有权，防止覆盖已有灯光。
