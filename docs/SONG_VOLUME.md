# 逐曲音量

内部主控模式下，每张音频节目卡片显示独立音量。停止播放后点击该按钮，在节目属性中设置 0–100%；0% 静音，100% 使用原始音量。通过 LinkCommand 保存到既有 playback.volume 字段，支持撤销及工程自动保存。

播放条的“临时音量”仅调整本次播放。切歌和重新定位按对应歌曲保存的音量播放；未设置的歌曲使用 100%，不继承上一首。淡入恢复到该歌曲设置的音量。

这里提供手动逐曲调节，不做自动响度分析或均衡处理。P1 跟随模式的正式音频仍由 P1 控制。

验证：播放控制器 15 项单测通过，包括不同歌曲、静音、切歌、定位和淡入。Electron 界面测试验证入口不触发播放、数值校验、撤销、磁盘保存及重开后保留独立音量。类型检查、Lint 和 Electron 构建通过。
