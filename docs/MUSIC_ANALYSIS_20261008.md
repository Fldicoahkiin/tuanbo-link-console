## RTX 4070 实际推理

CUDA PyTorch 2.7.1 的 3,273,066,072 字节 Windows 包已完整下载并校验 SHA256，安装于独立研究环境。CUDA 可用且设备为 RTX 4070；未采用 CPU 回退。

同一用户视频经完整 TypeScript 主进程适配器执行，未命中结果缓存：Python 分析 23.507 秒，主进程端到端 25.257 秒。结果在 `output/music-analysis/host-cuda-verified/host-report.json`。与 CPU 对照的音源摘要、PCM 摘要、采样数一致；三个 Beat This! 和 All-In-One 的全部普通拍时间数组一致，结构段落一致。对照记录为 `output/music-analysis/cpu-cuda-comparison.json`。

该结果仅证明此音源的 Windows GPU 部署可运行，不代表曲库正确率、召回率或五分钟首次分析 P95 达标。开发版面板明确选择 GPU／CPU；任一设备失败均返回错误，不自动换设备。

另将此片段循环至 300 秒，只作长音频性能负载：Python 分析 41.643 秒，主进程端到端 44.099 秒，未命中结果缓存。证据为 `output/music-analysis/host-cuda-300s/host-report.json`。重复片段不是新歌曲，不能计入曲库或声称已满足曲库 P95。

验收探针现会在每次运行目录保存分析源码快照，再执行该快照，使结果能对应具体处理版本。带源码的真实视频 GPU 运行位于 `output/music-analysis/host-cuda-source-snapshot/`，本次 Python 15.573 秒；系统文件／驱动缓存可能已热，不能把它与第一次耗时直接当作算法提速比例。
