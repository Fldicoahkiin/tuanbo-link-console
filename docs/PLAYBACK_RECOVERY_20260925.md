# 2026-09-25 素材播放状态恢复

本轮只修改、重启开发版，没有生成安装包。针对用户原工程中的透明扑克牌不能播放、暂停后定位无画面和本机播放误报 MTC 中断。

## 已确认的原因与修改

- 内部音频启动前，OBS 准备与音频加载耗时被计入 MTC 丢失判断。现在只在真实音频开始后启动内部时钟看门狗；暂停、定位、停止期间不检查内部播放丢码。重新锚定仅接受同帧率且不超过 250ms 的正向偏移，真实运行丢码与异常跳变仍阻断。
- 叠加场景必须先激活，再重播该场景内的媒体。原来的媒体优先顺序会使 OBS 接受重播但没有启动不可见的解码来源。现在相同时间点依次执行媒体结束、视觉组合、媒体开始。
- 片段结束使用停止而非暂停，避免留在片尾。暂停后继续不会再次重播或定位相同媒体。
- 原工程现场读回过 `PAUSED / 23ms / 2206ms`，但来源宽高均为零。原生定位应答只代表接受调用，不代表解码器已有画面。现在对结束或无帧的自有素材先启动解码，等真实首帧出现后再执行一次原生暂停定位，并校验暂停状态、实际位置与画面尺寸。正常已有画面的暂停不重启，超时明确失败，不自动重试。
- 原生通道首次定位需要查找监听端口所属的 OBS 进程。这一步现在先于素材启动执行，防止 2.2 秒短片在查找进程期间已经播完。首帧就绪同时检查重启后的实际播放位置，避免把上一轮片尾状态当成新解码结果。
- 下一帧与键盘步进保持按帧对齐，不再被鼠标拖动用的片段边缘吸附反复吸回零点。

## 验证

- Windows 11 / OBS 32.2.2，用户 `11111 联动工程` 与原始 `扑克牌特效.mov`。开发版完整重启后，从 1.2 秒开始播放，8 秒处第二段透明扑克牌叠加在下层视频上，继续运行到 25 秒后手动暂停，未出现本次定位失败或 MTC 中断。截图：`artifacts/playback-20260925/original-project-playing.jpg`。
- 单测 924 通过、40 跳过；覆盖慢启动、长暂停后继续、真实时钟中断、无首帧等待、片尾旧会话恢复及失败不重试。类型检查与 Lint 通过。
- 实际 OBS 回归使用隔离的便携 OBS、独立 Electron 用户目录和静音测试工程，不以模拟器替代真实视频解码；检查暂停、继续、停止、逐帧定位、中段重播、实际来源尺寸及预览绘帧。
- 最终真实 OBS 回归连续 3 次通过（18.8 / 18.7 / 18.4 秒），包括先让素材自然播放到结束，再从 0.8 秒重播并读回真实画面。日志 `playback-real-obs-acceptance.log`，中段截图与一轮预览采样保存于 `artifacts/playback-20260925/`。预览采样只证明短时响应，不代表长期 CPU/GPU/内存验收。
- 包含最后通道准备顺序修复的开发版重新打开原工程，实际连续播放至 21 秒后暂停，定位到 1 秒 6 帧，确认透明扑克牌叠加在下层原场景上；继续播放至 18 秒后正常停止，未出现本轮 MTC 中断或定位错误。定位证据：`artifacts/playback-20260925/original-project-final-seek.jpg`。开发版保留在原工程编辑器的停止状态。

## 第二段特效使底层停顿（后续修复）

上一轮只检查透明叠加出现，没有验证底层持续运动，遗漏了图层边界对已有视频的重复启动。`sceneBoundaryWork` 在叠加层变化时把所有可见素材重新发出开始事件；底层随后可能被暂停定位，造成特效进入时卡顿。

现在按片段 ID 比较前后可见集合，只启动新进入的片段。特效退出后，持续播放的底层仅收到场景选择动作，不重新启动或定位。完整定位及被机位遮挡后重新出现的素材仍沿用原有定位行为。

- 新增单测在修复前确认第二段进入时多发底层开始事件；修复后相关 29 项单测通过。
- 新增真实 OBS 双视频回归：第二段特效进入及退出期间采样 79 次，底层全部为播放状态，没有重复播放开始事件，媒体位置与实际时间推进最大偏差 19.6ms；两次底层源截图内容不同。
- 两项实际 OBS 回归通过（19.8s / 15.7s），包括之前的暂停、继续、定位及片尾重播。日志：`playback-overlay-continuity-verified.log`。
- 最终开发版原工程在 8.03 / 8.40 / 8.83 / 9.23 秒采集预览帧，确认扑克牌变化时底层人物仍在运动。证据：`artifacts/playback-20260925/second-overlay-*.png`。
- 本轮没有打包或提交。专用测试 OBS 的首次预览回归因未加载预览组件失败；为该隔离实例部署现有组件并重启后才重新验收通过，未修改个人 OBS 插件。
