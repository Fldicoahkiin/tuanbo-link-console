# 开发版一键连接故障修复与 Windows 验证（2026-10-14）

## 修复范围

- 解除本机 Windows MIDI 服务长期停留在 StopPending 的故障。精确核验服务 PID 与系统可执行文件后，按用户明确授权重启该故障服务；未重启整个 Windows、修改驱动或注册表。恢复后 onPC 出现主窗口，MIDI 探针返回 ready。
- 一键连接识别并启动配置中的 MA2 onPC 与 MA 3D。已有进程无主窗口时明确报错，不重复启动；先建立 onPC 通信，再启动 MA 3D。
- 本机连接在发送登录前检查两个实际 TCP 已建立连接的四元组与 onPC PID，防止错连 MA 3D 或另一版本 onPC。不能仅依赖 Windows 报告的监听端口所有者；MA 3D 可能显示为监听者，而实际接受连接的是 onPC。
- 开发构建使用独立启动器和文件标准输出；启动终端退出不再造成 Electron 写入失效管道的 EPIPE 弹窗。
- 外部程序使用独立进程生命周期，避免退出联动台时已选择保留的 MA 3D 随父进程结束；精确路径、PID、启动时间和所有权检查继续生效。
- 已读取的控台素材池作为当前池的唯一来源，不再把旧歌曲、绑定和模板中的已失效序列重新混入试听列表。空池与部分读取也不回退到旧素材；工程原有编排和引用保留。
- 精确 Off 的清理不再被“目标已不存在”的前置检查卡住，仍要求关联发送回执；断网、会话变化及未知结果继续明确失败。
