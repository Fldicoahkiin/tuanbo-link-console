# 快捷键

2026-11-11（0.5.9，04 设计 K7）。键位只在一张表里：`apps/desktop/src/renderer/src/link/keys/keymap.ts`。界面上写的键名（工具栏按钮的提示、右键菜单、「定位」菜单）都从这张表读，改表就跟着变。规则测试 `keys/key-routing-rules.test.ts` 守着下面这些用户定下的规则。

状态：已实现，自动化验证通过（单测、类型检查、lint）；**未实机验证**，剪映的键也还没在现场的剪映上核对（见第 4 节）。

## 1. 用户定下的规则

- **停止**（00-order 第 8 节第 1 题，取代 04 设计 4.10）：
  - Esc 照旧停止，按「输入框 → 弹窗 → 拖动 → 页面 → 全局」的顺序轮到它：输入框、对话框、打开的面板和拖动先拿走 Esc。
  - Shift+Esc 是第二个停止键，在哪儿都能停止：对话框开着、拖动中、输入框里、按钮和滑块上。它只停止，对话框不关，拖动不取消。它是“对话框里的键不碰节目”唯一的例外。录键的输入框（设置里改快捷键的框）照样把它录下来。
  - 「设置 › 播放 › 快捷键 › 单按 Esc 停止」，默认开，每台电脑记住（`localStorage` 的 `tblink.key-switches`，和 0.5.8 读的 `tblink.timeline-shortcuts` 分开存）。关掉后单按 Esc 只关面板、取消选中、取消拖动。
- **首页的键不变**：空格、开了「方向键切歌」时的 ↑↓、卡片上的 Enter、每首歌自己的快捷键。↑↓ 换歌只在首页。
- **编辑器和灯光工作台照剪映专业版的默认键**；和剪映不一样的地方在表里写了原因（`differsFromJianying`）。
- **按住 Enter 只算一次**：除了多行文字框，按住 Enter 时重复的按键由路由先拿走，按钮、表单、Go 执行器键、Cue 点和修改框都只收到第一下。

## 2. 键位表

### 全局（三个页面）

| 操作 | 键 | 说明 |
| --- | --- | --- |
| 停止 | Esc（可在设置里关掉）、Shift+Esc | 编辑器和灯光工作台里停止的是这一页的试听：音乐、MA2 试听和灯光预览一起停 |
| 保存 / 另存为 | Ctrl+S / Ctrl+Shift+S | 输入框和对话框里也能用 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y、Ctrl+Shift+Z | 输入框里归输入框，对话框里归对话框 |
| 播这首歌 | 每首歌自己设的键 | 时间线里不起作用 |

### 首页（不变）

| 操作 | 键 |
| --- | --- |
| 播放 / 暂停 | 空格 |
| 上一首 / 下一首 | ↑ / ↓（开了「方向键切歌」时） |
| 播放这张卡片 | 卡片上按 Enter |

| 删除 | Delete / Backspace | 编辑器新加 Backspace |

| 取消选中 | Esc | 只在关掉「单按 Esc 停止」时；开着时 Esc 停止 |

### 只在编辑器

| 操作 | 键 | 以前 |
| --- | --- | --- |
| 在播放头分割所有片段 | Ctrl+Shift+B | 新加；锁着的轨道不分，音频片段一起分 |
| 把开头 / 结尾修剪到播放头 | Q / W | 新加；和右键菜单「将开头/结尾修剪至播放头」一样，先看选中的音频片段，再看选中的片段或触发点 |
| 加时间线标记 | M | **以前是在灯光轨道上加灯光点**。灯光点在编辑器里改用双击灯光片段或右键「在这里打点」 |

### 只在灯光工作台（可在设置里改）

| 操作 | 键 |
| --- | --- |
| 在播放头打点 | M |
| 播放 / 暂停 | 空格 |
| 上一帧 / 下一帧 | ← / →（按住连续走） |
| 回到开头 / 跳到结尾 | Home / End |

## 3. 和设计（04 设计第 5 节）不一样的地方

- 停止键：设计是“只有 Shift+Esc 停止，单按 Esc 不停”；用户在 00-order 第 8 节第 1 题改成“Esc 照旧停止，加 Shift+Esc，加开关”。所以时间线上的 Esc 默认还是停止，只有关掉开关后才是取消选中。
- 编辑器的 Ctrl+X（剪切内容片段）没做：内容片段的剪贴板记的是片段本身，剪切后片段就没了，粘贴不出来。要做得先把剪贴板改成存一份片段的副本。Ctrl+X 现在只剪切灯光点（和以前一样）。
- N 照剪映是「自动吸附」开关，不是“跳到下一拍”；吸附点里有这首歌的节拍（`songBeats`）。
- 上一个 / 下一个标记（Shift+M / Alt+Shift+M）、启用/停用（V）、手动踩点（Ctrl+J）留给 K10。
- 改停止键、改编辑器的键留给 K8（设置页重写）。

## 5. 只能现场验证的

- Windows 上微软拼音、搜狗输入法开着时（焦点不在输入框），Shift+Esc 能停止，也不会切换中英文。
- 在对话框里、拖动中、输入框里按 Shift+Esc：节目停，对话框不关，拖动不取消。
- 按住 Enter：Go 执行器键、「下一首」按钮、Cue 点、修改框都只算一次（实体 MA2）。
- 按住 → 连续逐帧时 OBS 不卡、红字正常。
