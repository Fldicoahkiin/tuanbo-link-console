# 媒体库创建 OBS 来源

2026-09-10：媒体库空白区域右键或点击加号，支持视频采集、媒体、浏览器、窗口、文本、显示器、音频输入和音频输出。

流程：名称与目标场景 → 配置 → 应用并加入节目。设备选项来自 OBS 的真实属性列表，提交时再验证可用性。来源创建为隐藏草稿；参数回读一致后启用。取消或开发刷新清理本次未完成草稿，已应用来源留在 OBS 场景集合中。节目只保存现有 OBS 动作引用，沿用 Command、撤销与自动保存。OBS 来源配置由 OBS 保存，因此工程仍需连接原 OBS 场景集合。

场景模式加入完整场景切换动作；受管模式沿用来源片段。不会重设既有场景项的缩放、裁剪、滤镜或拉腿。音频输入不请求截图。不会控制推流或录制。

验证：16 项来源适配器测试；媒体库端到端测试覆盖八入口、设备选择、取消、文本参数传输、加入完整场景和自动保存。当前机器 OBS 32.2.2 实测视频设备枚举和取消清理通过（只有 OBS Virtual Camera 可选，未做实体摄像头画面验收）。其他设备的实际信号仍依赖现场硬件。
