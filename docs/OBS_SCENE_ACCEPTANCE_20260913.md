# OBS 场景联动验收

本记录对应用户提出的场景工作流、低功率切换、播放位置恢复、片段长度与错误提示需求。不能将下列局部验证解释为任何电脑、任何素材都没有问题。

| 需求 | 当前实现与证据 | 结论 |
| --- | --- | --- |
| 机位与 OBS 场景同步，保留显隐、拉腿、裁剪和滤镜 | `ObsMediaScenes.switchScene` 仅切场景，静音应用自有底层媒体；场景变化刷新资源列表；现有来源保护单测 | 已验证当前工作流 |
| 不再选择软件编排或 OBS 场景工作流 | 设置中无旧模式选择器，Electron 断言旧控件不存在 | 已验证 |
| 每个导入素材独立 OBS 场景 | 导入和预检调用准备服务；OBS 列表中的本工程素材场景拖入后建立媒体片段；Electron 验证保存结果 | 已验证视频流程及资源联动 |
| 机位结束恢复视频当前时间 | 当前工程首次播放 0 ms、机位结束恢复 8100 ms，连续两轮 OBS 切换后位置核对通过 | 已验证当前工程 |
| 机位期间暂停、继续 | 全部活动媒体暂停与继续，机位覆盖期间保持静音；本机中途暂停再继续后恢复 8100 ms | 已验证当前工程 |
| 场景片段长度和 UI 尺寸 | 新片段默认 5 秒，双端拖动，真实时间宽度和 43 px 高度；Electron 拖动与截图检查 | 已验证 |
| 低功率可切换且保留预览 | 开启卸载本地视频、OBS 预览及动态频谱，关闭恢复；Electron 验证元素移除与重挂载 | 已验证功能，不等于 GPU 占用为零 |
| 普通模式预览对应当前场景 | 复用场景时间线选择结果；本机机位时显示 OBS 场景 2，无本地视频；结束后视频在 9.66 秒继续 | 已验证当前工程 |
| 错误明确且不挤 UI，X 和点外部关闭 | 右侧频谱绝对定位覆盖层，预检信息包含节目与原因；Electron 关闭及紧凑窗口测试 | 已验证 |
| 任意视频位置定位 | 可选 JPEG 2000 无损定位缓存；原素材和缓存 SHA-256 校验；OBS 首次 2300 ms、向前 8100 ms、向后 5170 ms 实测成功 | 已验证这三个位置，须开启缓存 |
| 重启后首次定位和格式切换 | 重启联动台后 2300/8100/5170 ms 再测通过；去掉预检重播，仅正式启动时激活和重播，复测通过 | 已验证联动台重启；未重启用户 OBS/电脑 |
| 绝对 0 延迟 | 单次实测约 88–134 ms，无法据此保证 0 延迟；已询问用户是否接受按实际位置与耗时验收 | 未达到，等待用户确认标准 |
